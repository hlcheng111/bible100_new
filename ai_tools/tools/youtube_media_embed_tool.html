💡 使用說明 Usage Instructions

🎬 快速嵌入功能

  1. 在"YouTube視頻鏈接"框中輸入完整的YouTube URL
  2. 選擇需要的選項（自動播放、響應式設計、控制欄）
  3. 點擊"生成嵌入代碼"按鈕
  4. 複製生成的代碼到您的網頁中

⏰ 時間戳播放列表功能

  1. 輸入YouTube視頻ID或完整URL
  2. 使用示例時間戳或自定義時間戳列表
  3. 點擊"生成播放列表"按鈕
  4. 複製播放列表代碼到您的網頁中

🔧 實用技巧

  • 響應式設計： 選擇響應式選項可以讓視頻在不同設備上自動調整大小
  • 時間戳格式： 使用 HH:MM:SS 格式，例如 0:02:30 表示2分30秒
  • 批量處理： 可以一次性輸入多個時間戳，每行一個
  • 預覽功能： 使用預覽功能可以測試嵌入效果
  • 下載功能： 可以下載生成的代碼文件
