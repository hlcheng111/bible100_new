# AI智慧事奉 — 資訊圖說明

## 目的

與「聖經百步四寶」資訊圖同類：用**一張圖**呈現理念、核心流程與數位支援，方便教學、簡報或未來製成海報／社群圖。

## 現有檔案

- **ai_smart_ministry_infographic.html**  
  - 結構：主標 → 核心流程（七步）→ 數位支援模組 → 宗旨內涵／應用對象。  
  - 可於瀏覽器直接開啟，或另存／截圖為 PNG 使用。

## 未來可製作「類似資訊圖」的方向

1. **沿用版型**：保留「核心流程橢圓 + 步驟條 + 支援模組 + 宗旨／應用」四區塊，只改文案與配色。
2. **細化單一流程**：例如只做「性格測驗與恩賜調查 → 服事建議 → 服事配對」三階，搭配圖示與短句。
3. **多語版**：同一版型複製一份，標題與內文改為英文或簡中，方便對外或課程使用。
4. **匯出為圖**：用瀏覽器全頁截圖、或列印成 PDF 後轉 PNG，即可當作海報或簡報插圖。

## 與聖經百步四寶的對應

| 四寶資訊圖           | AI智慧事奉資訊圖           |
|--------------------|----------------------------|
| 四階循環（讀背應用教導） | 七步事奉流程（呼召→調查→建議→配對→吸納→管理→使命） |
| 數位支援（AI／目錄／門訓） | 數位支援（AI工具／問卷／配對／儀表板／門訓） |
| 宗旨內涵（四寶與支援）   | 宗旨內涵（事奉與人才、恩賜配對、教會使命） |
| 全方位應用對象         | 個人／小組／主日學／各部門事奉規劃         |

完善流程與文案後，可直接在 `ai_smart_ministry_infographic.html` 上微調，或另存新檔製作第二、第三張同風格資訊圖。
