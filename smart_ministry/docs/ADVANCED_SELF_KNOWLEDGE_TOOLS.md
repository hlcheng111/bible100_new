# 進階自我認識工具（MBTI 簡化版 · DISC · SHAPE）

**定位**：培訓／陪談用的**自願工具**，與「信徒／教牧靈命健康問卷」「屬靈恩賜主線卷」**分開**。

**路徑**：`mbti_test.html`、`test01_disc_test_grok.html`、`test02_shape_test_grok.html`  
**主線（不取代）**：`registration.html`、`spiritual_gifts.html`

---

## 一、共同原則

1. **不接** `spiritual_health_scoring.js`；**不產生**紅／黃／綠或任何「整體健康」指標。  
2. **不**與信徒／教牧健康卷、恩賜卷的得分做**數學加總或混合**。  
3. 題目介面：**1–5 pill**（1＝非常不符合／完全不像我 ··· 5＝非常符合／非常像我），與主線問卷視覺一致。  
4. 結果：**結構化文字描述** + **2～3 個反思問題**；引導與牧者／導師對話，**不是**靈命成績單或服事資格門檻。  
5. 頁頂必備：**用途、限制（非診斷）、建議陪談、預估作答時間**。

---

## 二、MBTI 簡化版（`mbti_test.html`）

- **題數**：12 題（E–I、S–N、T–F、J–P 各 3 題）。  
- **計分**：每維度該組題目**算術平均**，保留一位小數；**不**在畫面上顯示四字母型號。  
- **敘述規則**：平均 ≥3.5 →「偏向」高量表端；≤2.5 →「偏向」另一端；其餘 →「介於兩端之間」。  
- **儲存**：`bible100_smart_ministry_survey_mbti`（結構含 `schemaVersion: 2`、`dimensionScores`、敘述文字）。  
- **向後相容**：可內部推算 `derivedType`（四字母）寫入 `survey_profile.mbti_type` 供舊版配對／追蹤邏輯使用，但**使用者介面不得展示**該代碼。

---

## 三、DISC（`test01_disc_test_grok.html`）

- **題數**：D／I／S／C 各 7 題，共 28 題；可**分頁**（例如每頁一維度）。  
- **計分**：每維度**平均**（1–5），保留一位小數；**不**產生單一「總分」或健康指數。  
- **結果**：四向度**並列**（條狀圖僅表示相對高低）；每向度一小段**優點＋提醒**（牧養口吻）；**不**將某一型標為「最好」。  
- **儲存**：`bible100_smart_ministry_survey_disc`（含各維度平均）；`survey_profile.disc_type` 可保留為「平均最高之維度字母」供相容，但 UI 以四向度並陳為主。

---

## 四、SHAPE（`test02_shape_test_grok.html`）

- **非**純量表總分；為 **S-H-A-P-E 結構化表單** + **事奉故事卡**輸出。  
- **S**：優先讀取 `survey_spiritual_gifts`／`survey_profile.spiritual_gifts`；可手動補充。  
- **H／A／E**：開放題或勾選；**P**：可帶入 MBTI 簡化版與 DISC 之**文字摘要**（非混合計分）。  
- **輸出**：一段整合敘述 + 若干「可能合適的服事方向」（**文字建議**，非自動派工）+ 反思問題。  
- **儲存**：`bible100_smart_ministry_survey_shape`（JSON）；**不**參與 health scoring。

---

## 五、給 Cursor／維護者的約束（必須遵守）

1. **不可**讓此三工具 `import` 或呼叫 `spiritual_health_scoring.js`。  
2. **不可**將此三者分數與教會健康問卷、恩賜主線卷做加權或合併公式。  
3. 調整題目時，**僅能在同一維度、同一心理學向度內**換句或增刪題；**不可**擅自新增維度或改框架名稱（例如把 DISC 改成 Big5）。  
4. 若新增可視化，**僅限於該工具頁內**（如 DISC 四條比較條），並在本檔補一句說明。  
5. UI **不得**將進階工具結果展示為「通過／不通過」或紅綠燈。
