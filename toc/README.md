# Bible100 智能目錄系統 (TOC)

## 📋 **系統概述**

Bible100智能目錄系統是一個自動化的網站目錄生成工具，專為多模組、多語言的聖經學習平台設計。系統能夠智能掃描所有HTML文件，按模組和語言分類組織，生成統一的站點目錄。

## 🎯 **核心特性**

### ✅ **智能掃描**
- 自動掃描所有模組文件和語言版本
- 智能識別文件類型和結構
- 排除無關文件和目錄

### ✅ **模組分類**
- 按模組分類組織：聖經閱讀、聖經研讀、AI工具等
- 每個模組包含主頁、儀表板、功能頁面
- 支持模組優先級和啟用/禁用

### ✅ **多語言支持**
- 支持6種語言版本：中文、英文、越南語、印尼語、兒童版、進階版
- 每個語言版本獨立目錄
- 語言特定的文件組織

### ✅ **平板優化**
- 響應式設計，完美適配PC、平板、手機
- 觸摸友好的界面設計
- 優化的加載性能

### ✅ **手動觸發**
- 按需生成，避免自動掃描造成的性能問題
- 可控制的生成過程
- 實時進度顯示

### ✅ **可重用設計**
- 通用架構，可輕鬆移植到其他網站
- 配置文件驅動
- 模板系統支持自定義

## 📁 **文件結構**

```
toc/
├── index.html              # 主控制頁面
├── toc-generator.js        # 核心生成器
├── toc-templates.js        # 模板引擎
├── toc-styles.css          # 樣式文件
├── toc-config.json         # 配置文件
├── README.md              # 說明文檔
└── generated/             # 生成的文件目錄
    ├── site-map.html      # 主站點目錄
    ├── modules/           # 各模組目錄
    │   ├── bible_study-toc.html
    │   └── ...
    └── languages/         # 各語言目錄
        ├── cn-toc.html
        ├── en-toc.html
        └── ...
```

## 🚀 **使用方法**

### **步驟 1: 訪問控制頁面**
```
http://your-domain/toc/index.html
```

### **步驟 2: 生成目錄**
1. 點擊「開始生成目錄」按鈕
2. 等待掃描完成（約1-2分鐘）
3. 下載生成的目錄文件

### **步驟 3: 部署文件**
1. 將生成的文件放置到網站根目錄
2. 通過主頁訪問生成的目錄
3. 享受統一的導航體驗

## ⚙️ **配置說明**

### **模組配置**
```json
{
  "modules": [
    {
      "name": "bible_study",
      "title": "聖經研讀",
      "icon": "📖",
      "priority": 1,
      "enabled": true
    }
  ]
}
```

### **語言配置**
```json
{
  "languages": [
    {
      "code": "cn",
      "name": "中文",
      "flag": "🇨🇳",
      "enabled": true
    }
  ]
}
```

### **掃描設置**
```json
{
  "scanSettings": {
    "excludePaths": ["archive/", "backup/", "temp/"],
    "excludeFiles": ["*.tmp", "*.log", "*複製*"],
    "includeExtensions": [".html", ".htm"],
    "batchSize": 50
  }
}
```

## 🔍 **故障排除**

### **常見問題**

#### **Q: 生成失敗怎麼辦？**
A: 檢查文件權限，確保有寫入權限，查看控制台錯誤信息。

#### **Q: 某些文件沒有被掃描？**
A: 檢查 `excludePaths` 和 `excludeFiles` 配置，確保文件不在排除列表中。

#### **Q: 生成的目錄樣式不正確？**
A: 確保 `toc-styles.css` 文件路徑正確，檢查CSS文件是否加載。

#### **Q: 移動端顯示異常？**
A: 檢查響應式CSS是否正確加載，確保viewport設置正確。

### **調試方法**
1. 打開瀏覽器開發者工具
2. 查看控制台錯誤信息
3. 檢查網絡請求狀態
4. 驗證文件路徑正確性
