# hymn_management 清理與上傳清單

## 寄傳商單檔限制（約 2MB）

常見虛擬主機、Blog 平台單檔上傳限制為 **2MB**（如 cPanel 預設、Blogger 圖片 8MB）。為符合限制，已做以下調整：

1. **source-hymns.json**：已分割為 4 個檔案（各 <1.3MB），由 `source-hymns-loader.js` 自動合併載入
2. **hymn/image_hymn/**：有 1 個檔案超過 2MB 待確認（`img_0941.jpg`）；其餘 3 檔已移除（見下方）

## 四、方案 B 上傳前準備

1. **執行分割腳本**（若尚未執行）：
   ```bash
   cd hymn_management && node scripts/split-source-hymns-for-upload.js
   ```
   會產生 `data/source-hymns-1.json`～`4.json` 與 `source-hymns-manifest.json`，並將 `C:/hymn/` 改為相對路徑。

2. **處理超過 2MB 的檔案**：
   - `bible-hymnal (www.ccog.org).pdf`、兩張 `Screen-Shot-*.png` — **已移除**（PDF 全除；Screen-Shot 已改外部連結）
   - `img_0941.jpg` — 待確認，可壓縮至 <2MB 或保留

3. **不要上傳** 原始 `data/source-hymns.json`（5MB，會超限）；上傳分割檔即可。

## 五、建議執行順序

1. **刪除可刪檔案：** `start_http_聖詩.bat`、`hymn/scripts/node_modules/`（若不再本地建置）
2. **執行分割腳本**（方案 B 必做）
3. **建立部署清單：** 依方案 A/B 建立要上傳的檔案清單
4. **驗證：** 上傳後檢查 index.html、詩歌編輯器、PPT 生成器、崇拜流程建設器是否正常
