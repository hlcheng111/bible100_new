## 🔗 链接处理策略

### 核心要求：
1. ❌ 不修改任何原始歌曲.htm文件
2. ❌ 不修改default - 複製.htm（Big5）
3. ✅ 只修改新创建的TOC文件（UTF-8）

### 链接生成方法：

#### **方法：在TOC中正确设置target**

**在hymn_most_toc.html中：**
```javascript
生成链接时：
• href = "hymn_most/文件名" (正确URL编码)
• target = "main" (指向content frame)
• 不是 target = "_blank"

关键：
• TOC文件在sidebar frame中
• 点击链接时，target="main"告诉浏览器
  在名为"main"的frame中打开
• content frame的name="main"
• 自动匹配！无需复杂编程
```

**这是frameset的标准机制，完全可行！** ✅

## 🔧 技术实现要点

### 1. Frameset的target机制

**工作原理：**
```html
主框架：
<frameset>
  <frame name="contents"> ← Sidebar
  <frame name="main">     ← Content
</frameset>

Sidebar中的链接：
<a href="hymn_most/0604...htm" target="main">歌名</a>
                                    ↑
                            指向name="main"的frame

结果：
点击链接 → 自动在main frame中打开 → 不开新窗口
```

**这是HTML标准功能，无需JavaScript，100%可靠！** ✅

---

### 2. 边界拖拽功能

**Frameset内置功能：**
```html
<frameset cols="204,*">  ← 没有noresize属性
  ↑ 用户可以拖拽这个边界
  ↑ 浏览器自动处理，无需编程
```

**用户操作：**
- 鼠标移到两个frame之间的边界
- 出现 ↔ 光标
- 拖动 → 改变sidebar宽度
- 释放 → 固定新宽度

**实现难度：** 🟢 免费（0行代码）

---

### 3. 文件夹切换机制

**实现思路：**
```javascript
Top Frame中的函数：

function switchFolder(folderName) {
  // 找到对应的TOC文件
  var tocFiles = {
    'hymn_most': 'toc/hymn_most_toc.html',
    'hymn_chi': 'toc/hymn_chi_toc.html',
    'hymn_00': 'toc/hymn_00_toc.html',
    ...
  };
  
  // 改变sidebar的src
  parent.frames['contents'].location = tocFiles[folderName];
  
  // 更新下拉菜单显示
  updateFolderDisplay(folderName);
}
```

**触发方式：**
- 用户在top frame选择文件夹
- 或点击sidebar中的"返回文件夹列表"
- 或全局搜索结果中点击文件夹名

---

### 4. 链接URL编码处理

**核心策略：从实际文件名生成链接**

**处理流程：**
```
步骤1：读取文件名
"0604 To God be the Glory  _ Fanny Crosby  榮耀歸於真神 ▲.htm"
              ↑           ↑
          普通空格  不间断空格(160)

步骤2：检测空格类型
• 扫描每个空格字符的Unicode值
• 32 = 普通空格 → %20
• 160 = 不间断空格 → %C2%A0

步骤3：正确编码
"hymn_most/0604%20To%20God%20be%20the%20Glory%20%20_%C2%A0Fanny%20Crosby..."

步骤4：验证
• Test-Path检查文件是否存在
• 不存在 → 标记"链接待修复"
```

**成功率预估：**
- hymn_most：90-95%可自动正确
- 其他文件夹：80-90%
- 剩余手工修复
