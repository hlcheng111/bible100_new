## 🎯 功能说明

### 1. 排序功能
- **[Sort by No.]** - 按编号排序（0001-9999）
- **[Sort by EN Title]** - 按英文歌名字母排序
- **[Sort by CH Title]** - 按中文歌名排序
- **[Sort by Author]** - 按作者姓名排序
- **[Sort by Tags]** - 按标签排序
- **[Reset]** - 恢复原始顺序

**使用方式：**
- 点击任一按钮 → 升序排序（按钮显示 ↑）
- 再次点击 → 降序排序（按钮显示 ↓）
- 点击[Reset] → 恢复原始顺序

---

### 2. 搜索功能
- 输入关键词即时搜索
- 搜索范围：编号、英文歌名、中文歌名、作者、标签
- 不区分大小写
- 支持部分匹配

**示例：**
- 搜索 `Wesley` → 显示所有Wesley作曲的诗歌
- 搜索 `奇异` → 显示包含"奇异"的中文歌名
- 搜索 `0604` → 显示编号0604的诗歌

---

### 3. 标签系统
- **⭐推荐** - 文件名中有 ▲ 符号
- **🇨🇳华人** - 文件名中有 [華] 标记

---

### 4. 表格栏位
| 栏位 | 说明 | 可否编辑 |
|------|------|---------|
| No. | 诗歌编号 | - |
| English Title | 英文歌名（可点击打开真实文件） | - |
| 中文歌名 | 中文名称 | - |
| Author | 作者姓名 | - |
| Tags | 特征标签 | - |
| A/B/C/D/E | 诗集编号（预留） | 待添加 |
