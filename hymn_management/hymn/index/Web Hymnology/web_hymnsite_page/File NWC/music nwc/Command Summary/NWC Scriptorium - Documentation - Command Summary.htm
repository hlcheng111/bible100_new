Documentation -
Command Summary

A command summary for NoteWorthy Composer, originally created by Barry Graham in 1998, has now been updated (December 2000) for NWC v1.70 by Richard Woodroffe, with assistance from Fred Nachbaur and Jason Walker. This 171 page book is a must read for new (and seasoned) NoteWorthy Composer users.
It is available in PDF, PostScript and the original MS Publisher formats.
Click here for the complete PDF file (ZIPped, 1.1Mb).
