## 🚀 快速入門

### 第一步：打開系統

1. 在瀏覽器中打開 `main_homepage.html`
2. 等待系統初始化完成（約2-3秒）
3. 看到"系統初始化完成"通知即表示成功

### 第二步：認識界面

系統採用 **topbar → sidebar → content** 的經典佈局：

- **Topbar（頂部欄）**: 系統標題、搜索框、快捷按鈕
- **Sidebar（側邊欄）**: 功能導航菜單
- **Content（內容區）**: 主要功能展示區域

### 第三步：開始使用

點擊側邊欄的 **"📚 聖詩欣賞研究"** 即可進入主功能區。

## 📊 聖詩資料庫使用指南

### 1. 聖詩列表瀏覽

#### 基本操作
1. 點擊 **"📋 聖詩列表"**
2. 系統自動載入所有聖詩
3. 使用搜索框快速查找特定聖詩
4. 使用分類篩選器按類型瀏覽

#### 搜索技巧
- **編號搜索**: 輸入"0538"查找特定編號
- **標題搜索**: 輸入"聖哉三一"查找中文標題
- **作者搜索**: 輸入"Charles Wesley"查找作者
- **組合搜索**: 同時使用多個關鍵詞

#### 分類說明
- **讚美詩**: 讚美上帝的詩歌
- **崇拜詩**: 用於崇拜聚會的詩歌
- **節期詩**: 特定節期的詩歌
- **福音詩**: 傳福音用的詩歌

### 2. 聖詩搜索功能

#### 站內搜索
- 搜索本地數據庫中的所有聖詩
- 支持全文搜索（歌詞、標題、作者）
- 結果按相關度排序

#### 站外搜索
系統整合了多個外部資源：

**📚 Hymnary.org**
- 全球最大聖詩數據庫
- 包含歷史資料、多語言版本
- 使用方法：點擊 → 輸入關鍵詞 → 自動跳轉

**🎥 YouTube**
- 聖詩視頻資源
- 包含演唱、教學、伴奏版本
- 使用方法：點擊 → 輸入歌名 → 觀看視頻

**🎵 Spotify**
- 聖詩音頻資源
- 高品質錄音版本
- 使用方法：點擊 → 輸入歌名 → 收聽音頻

**📖 Google Scholar**
- 聖詩學術論文
- 研究資料、歷史文獻
- 使用方法：點擊 → 輸入研究主題 → 查看論文

### 3. 歌集瀏覽

#### 主要歌集
- **世紀頌讚**: 現代中文聖詩集
- **新編讚美詩**: 傳統中文聖詩集
- **英文聖詩集**: 經典英文聖詩

#### 瀏覽方法
1. 點擊 **"📖 歌集瀏覽"**
2. 選擇要瀏覽的歌集

4. 點擊聖詩查看詳細信息

#### 如何提問（Prompt指導）

**基礎提問格式**:
```
請分析這首聖詩的文學特點：
[聖詩標題]
[聖詩歌詞]

請從以下角度分析：
1. 文學體裁
2. 修辭手法
3. 神學主題
4. 歷史背景
```

**進階提問技巧**:
- **具體化**: 不要問"這首詩怎麼樣"，要問"這首詩的韻律結構如何"
- **多角度**: 從文學、神學、歷史多個角度提問
- **比較分析**: "比較這兩首聖詩的異同"
- **創作指導**: "如何改寫這首聖詩使其更適合現代崇拜"

## ❓ 常見問題解答

### Q1: 系統無法正常加載怎麼辦？
**A**: 
1. 檢查瀏覽器是否支持JavaScript
2. 清除瀏覽器緩存
3. 嘗試使用Chrome或Edge瀏覽器
4. 檢查文件路徑是否正確

### Q2: 搜索結果不準確怎麼辦？
**A**:
1. 嘗試使用不同的關鍵詞
2. 檢查拼寫是否正確
3. 使用更具體的搜索詞
4. 嘗試使用分類篩選

### Q3: 如何備份我的研究筆記？
**A**:
1. 系統會自動保存到瀏覽器本地存儲
2. 可以導出筆記為文本文件
3. 建議定期手動備份重要內容
4. 可以複製到其他文檔軟件

### Q4: 如何與他人分享研究成果？
**A**:
1. 使用導出功能生成分享文件
2. 通過協作平台邀請他人
3. 創建公開的研究報告
4. 使用社交媒體分享

### Q5: AI功能需要付費嗎？
**A**:
1. 推薦的AI平台都有免費版本
2. 免費版本通常有使用限制
3. 可以根據需要選擇付費版本
4. 系統本身完全免費
