# 🎵 聖詩智能分解與媒體導入系統 v2.0

## 📖 系統概述

這是一個完整的聖詩數據管理系統，能夠：
1. **智能分解** 2000+聖詩表格數據，自動提取編號、標題、作者、分類等信息
2. **保留所有原始鏈接**，確保數據完整性
3. **自動導入數據庫**，建立8個模組的完整數據結構
4. **支持YouTube播放列表** 批量導入，智能匹配聖詩
5. **提供完整的報表系統**，支持多維度查詢和分析

## 🏗️ 系統架構

### 核心組件
- **`smart_decomposition_engine.js`** - 智能分解引擎
- **`database_core_enhanced.js`** - 增強版數據庫核心（8模組）
- **`smart_decomposition_interface.html`** - 完整用戶界面

### 8個數據庫模組
1. **詩歌主表 (hymns)** - 存儲聖詩基本信息
2. **曲調表 (tunes)** - 存儲音樂曲調信息
3. **人物表 (people)** - 存儲作者、作曲者信息
4. **歌集表 (hymnals)** - 存儲不同版本的聖詩集
5. **分類表 (categories)** - 存儲分類和標籤信息
6. **媒體表 (media)** - 存儲相關媒體文件
7. **路徑管理表 (paths)** - 管理文件路徑和目錄
8. **關聯關係表 (relationships)** - 管理各模組間的關聯

## 🚀 使用方法

### 1. 智能分解聖詩數據

#### 步驟1：選擇表格
- 打開 `smart_decomposition_interface.html`
- 在"智能分解"標籤中選擇要分解的表格
- 系統會自動掃描頁面中的所有表格

#### 步驟2：開始分解
- 點擊"🚀 開始智能分解"按鈕
- 系統會自動解析每行數據，提取：
  - 編號（4位數字）
  - 英文標題
  - 中文標題
  - 作者信息
  - 分類代碼
  - 重要性標記（▲▲、▲、★、●、◆）
  - 原始鏈接和路徑

#### 步驟3：查看結果
- 系統會顯示分解統計：成功數量、失敗數量
- 失敗的記錄會列出具體原因
- 所有成功的數據會自動導入數據庫

### 2. YouTube播放列表導入

#### 方法1：URL直接解析
```
1. 貼上YouTube播放列表URL
2. 點擊"🔗 解析播放列表"
3. 系統會自動提取歌曲列表和時間戳
4. 點擊"✅ 確認導入媒體"
```

#### 方法2：手動貼入內容
```
1. 複製播放列表內容（包含時間戳和歌名）
2. 貼入文本框
3. 點擊"📝 解析文字內容"
4. 系統會自動解析每行內容
5. 點擊"✅ 確認導入媒體"
```

#### 智能匹配機制
- **精確匹配**：完全相同的歌名
- **部分匹配**：包含關係的標題
- **模糊匹配**：使用Levenshtein算法計算相似度（>70%）

### 3. 數據庫管理

#### 導出數據庫
- 點擊"💾 導出數據庫"
- 系統會生成JSON格式的完整備份
- 包含所有8個模組的數據

#### 導入數據庫
- 點擊"📂 導入數據庫"
- 選擇之前導出的JSON文件
- 系統會恢復完整的數據庫狀態

#### 完整性檢查
- 點擊"🔍 檢查完整性"
- 系統會檢查外鍵關聯
- 報告任何數據不一致問題

### 4. 報表查詢

#### 總覽報表
- 顯示各模組的統計數據
- 詩歌總數、媒體數量、作者數量等

#### 詩歌列表報表
- 顯示所有詩歌的詳細信息
- 支持分頁顯示（每頁20條）

#### 分類統計報表
- 按分類統計詩歌數量
- 顯示分類層級結構

#### 媒體關聯報表
- 顯示所有媒體文件
- 關聯的聖詩信息

#### 作者統計報表
- 顯示所有作者/作曲者
- 包含國籍、類型等信息

## 🔧 技術特點

### 智能解析規則
```javascript
// 編號模式：4位數字開頭
numberPattern: /^(\d{4})/

// 英文標題：大寫字母開頭
englishTitlePattern: /([A-Z][A-Za-z\s\-\'\"\.]+?)(?=\s*[_\-\()]|\s*$)/

// 作者：括號內或下劃線後
authorPattern: /[_\-\()]([A-Za-z\s]+?)[\)]?/

// 中文標題：中文字符
chineseTitlePattern: /[\u4e00-\u9fff]+/g

// 分類代碼：H開頭後跟數字和連字符
categoryPattern: /H\d{2}-\d{2}/

// 重要性標記
importancePattern: /[▲★●◆]+/g
```

### 數據持久化
- 使用 `localStorage` 自動保存到瀏覽器
- 支持JSON格式的導入/導出
- 數據不會因頁面刷新而丟失

### 錯誤處理
- 完整的錯誤捕獲和報告
- 失敗記錄的詳細說明
- 系統日誌記錄所有操作

## 📞 技術支持

### 常見問題
1. **系統無法啟動**
   - 檢查瀏覽器是否支持ES6+
   - 確認JavaScript文件已正確載入

2. **智能分解失敗**
   - 檢查表格格式是否正確
   - 查看系統日誌中的錯誤信息

3. **媒體導入不匹配**
   - 檢查歌名是否完全一致
   - 使用手動匹配功能

### 調試方法
1. 打開瀏覽器開發者工具（F12）
2. 查看控制台錯誤信息
3. 檢查系統日誌
4. 驗證數據庫完整性
