# 圣诗智能目录系统 - 项目规则文档

## 📌 项目概述

**项目名称：** 圣诗智能目录系统（Hymn Intelligent TOC System）

**项目目标：** 为 C:\hymn 文件夹下的所有圣诗文件创建智能化、可搜索、可排序的目录系统

**核心原则：**
- ❌ 不修改任何现有的真实歌曲页面
- ❌ 不改变原有文件的编码
- ✅ 创建全新的独立TOC文件
- ✅ 100%准确的文件链接（从实际文件名生成）
- ✅ UTF-8编码（现代化标准）

## 🔧 文件名解析规则

### 识别的文件名模式：

**模式1：标准格式**
```
编号 英文歌名_作者 中文歌名 符号.htm
示例：0604 To God be the Glory _Fanny Crosby 榮耀歸於真神 ▲.htm
```

**模式2：无作者**
```
编号 英文歌名 中文歌名 符号.htm
示例：0001 All people that on earth do dwell ▲ 普天之下萬民萬族.htm
```

**模式3：复杂格式**
```
编号 编号2 英文歌名 _ 作者 中文歌名 (注释) 符号.htm
示例：0005 0037 Let All Things... _ Katherine K. Davis 凡有氣息... (同獻...) ▲.htm
```

**模式4：含曲调名**
```
编号 歌名 _作者 中文 曲调名 符号.htm
示例：0002 O Worship the King _Robert Grant 來敬拜榮耀王 ▲.htm
```

### 解析优先级：

1. **编号提取**：正则 `^(\d{4}|\w+\d{4})` 
2. **符号识别**：搜索 ▲、●、◆、★、[華] 等
3. **作者提取**：查找 `_` 后的英文名（如果有）
4. **英文歌名**：编号后到 _ 或中文前
5. **中文歌名**：Unicode中文字符部分
6. **其他信息**：剩余部分（曲调、注释等）

### 无法解析的处理：

```
标记：parseStatus = "partial" 或 "failed"
显示：在TOC中用特殊颜色标注
操作：用户可以手工编辑这些条目
数量：预计5-10%（约10-20个文件）
```

## 🔗 链接生成规范

### URL编码标准：

**处理规则：**
```
1. 普通空格 → %20
2. 不间断空格（字符160） → %C2%A0
3. 中文字符 → UTF-8百分号编码
   例：榮 → %E6%A6%AE
4. 特殊符号：
   ▲ → %E2%96%B2
   ● → %E2%97%8F
   ◆ → %E2%97%86
   ★ → %E2%98%85
5. 标点符号：保持原样或编码
   , → %2C (可选)
   ( → %28
   ) → %29
```

**验证机制：**
```
生成链接后：
1. 构建完整路径：hymn_most/ + URL编码后的文件名
2. 用PowerShell Test-Path验证文件存在
3. 如果不存在，标记为"链接失效"
4. 尝试模糊匹配找到正确文件
```

## 🚀 功能规格说明

**交互方式：**

- 再次点击 → 降序

- 不区分大小写
- 支持部分匹配
- 高亮显示匹配内容

**高级搜索：**
- 按标签筛选：点击标签 → 只显示该标签诗歌
