🤖 詩歌 AI 工作臺

像 AI 工具中心一樣：先學流程 → 選平台 → 複製 Prompt → 人審後存檔。本站不代呼叫 API，全部外連。

⚠️ 教會使用原則：AI 產出只是草稿；神學分析非權威教義；文生音樂不能取代出版樂譜；版權與公開播映須人審。

📋 四步驟（小白照做）

1
選詩歌

在左側播放列表點歌，或下方輸入 ID 載入。

2
生成 Prompt

按「分析」或「文生音樂」產生文字，再複製。

3
外開 AI 平台

貼到 ChatGPT / Kimi / Suno，由您登入操作。

4
人審存檔

詩歌編輯器 + 啟動 hymn-data-server → 存 hymn-overrides。

❓ 常見問題

為什麼不在網站內直接跑 AI？

免 API 費、免金鑰外洩、各教會可自選平台；符合 Bible100「AI 草稿須人審」原則。

分析結果怎麼存回詩歌庫？

雙擊 START-HYMN-DATA-SERVER.cmd → 開 hymn_editor.html → 貼上審核後文字 →「存到 hymn-overrides」。

文生音樂可以當主日伴奏嗎？

不建議。僅作流程試聽；正式崇拜請用出版樂譜或教會已有授權素材。

與 ai_tools 總站什麼關係？

本頁專注詩歌情境；通用 AI 工具請見 AI 工具中心。
