# Practical Hymnology｜UI 母規約

2026-10-04 入檔。適用：總地圖、前言、分析範本、十五種看法、六條小路、學科山脈、課文、工作台、研究、證據，以及以後的新頁。

會眾看見的標題用白話，見 `PH_MASTER.md`。本檔裡的 Journey、26 Core、Prism 是在說哪一種內容，不是叫頁面改回那些英文大標。

## 1. 不要千篇一律的盒子

禁止把所有頁做成：卡片、卡片、卡片、按鈕、卡片。

禁止每個段落都用同一套白底、圓角、陰影、框線、內距、字級、排列。

畫面不是把資料裝進盒子。

## 2. 視覺為內容服務

做一個主要模組之前先問：這個內容本身最適合什麼樣子？

可以用：路線、地圖、節點、山脈、書頁、手稿、時間軸、放射圖、樹、河流、譜架、樂章、印章、標記、小旗、章節帶、圖譜、對照、分層文字、圖像式導航。

不能為了好看亂加。形式必須解釋內容。

對照：

| 內容 | 優先的樣子 |
|---|---|
| 路線 | 路 |
| 歷史 | 時間軸 |
| 地理 | 地圖 |
| 十五種看法 | 放射 |
| 學科 | 山 |
| 人物 | 肖像加時間 |
| 版本 | 對照 |
| 歌詞 | 書頁、手稿 |
| 音樂 | 譜、可聽 |
| 崇拜 | 流程 |
| 神學 | 概念關係 |
| 證據 | 分層、抽屜 |
| 分析範本 | 地標 |
| 六條小路 | 支線、小旗 |
| 換你來 | 工作台 |
| 資料 | 表、索引 |
| 搜尋 | 找、篩 |

## 3. 顏色要有意思

顏色要回答：這色代表什麼。

現用的一組意思（可以調，意思不要丟）：

| 意思 | 氣質 |
|---|---|
| 遇見 | 晨光、溫 |
| 看見 | 生長 |
| 追問 | 水、深 |
| 查證 | 墨、證據 |
| 回來 | 夕光 |
| 分析範本 | 路、土地 |
| 十五種看法 | 多方向 |
| 六條小路 | 小徑、旗 |
| 學科山脈 | 遠山 |
| 怎樣查證 | 深色、可核對 |
| 換你來 | 新的光 |

整體要成熟、安靜、有人味。禁止霓虹、大面積高飽和撞色、軟體儀表板配色、遊戲配色。

## 4. 中文是主角

主要閱讀語言是繁體中文。英文是副標。

```text
中文主標
English secondary label
```

不可以英文大標題、中文變成附註。

## 5. 字體

2026-10-04 起，新頁與日後改版以本節為準。

楷體負責人、路、歌、思想：頁首大標、段落標題、路上的站、歌名、分類、看法名、小路名、學科名、提醒、重要引文。

```css
"DFKai-SB", "BiauKai", "標楷體", "KaiTi", "STKaiti", serif
```

長文閱讀用宋體：

```css
"PMingLiU", "Songti TC", "Noto Serif TC", serif
```

英文用 Palatino、Georgia、Iowan Old Style 一類，斜體小字即可。

不可以整站只有黑體。既有前言、十五種看法短頁、分析範本地圖目前仍是黑體；未另開「改字」一輪時，不要在別的任務裡順手改掉。

## 6. 字級要有層次

不要每段都是同一號標題加同一號正文。要能分出：大標、副標、小標、節點字、英文副標、引文、正文、註、資料小字。

## 7. 品牌一致，版面不必相同

同一種氣質，不是同一套版型。

| 頁 | 樣子 |
|---|---|
| 前言的五旅 | 路線 |
| 分析範本 | 地標地圖 |
| 十五種看法 | 放射 |
| 學科 | 山 |
| 一課 | 閱讀加研究桌 |
| 證據 | 可核對的工作層 |
| 工作台 | 真的工具 |

## 8. 看起來能點，就要是入口

節點要能點。點了之後：走到本頁某一段、打開內容、進入真頁，或清楚寫「準備中」。

禁止假連結。禁止看起來能按、其實只是裝飾。沒有正式頁就不要造網址。可以先把路和門做出來，房間以後再經營。

## 9. 大型學習頁要讓人知道自己在哪

可用頂端頁籤、側邊目錄、章節索引、頁內錨點、進度路線。按該頁內容選，不是每頁都貼同一條。

## 10. 數字不是成績

二十六、十五、六、一百一十一是地圖的尺度，不是完成率。不要顯示 26/26、15/15、111 項任務。真有學習進度系統之前都不做。

## 11. 手機要重排，不是只壓窄

直向的路、可折疊的段、覆蓋式目錄、橫向頁籤、可展開的節點、夠大的按處。窄了仍要看得出方向和層次。

## 12. 實作不改內容思想

不改課程理念、二十六首、十五種看法、一百一十一科代碼、證據標準。不添加未核准的神學、不編歷史、不編音樂資料。

## 13. 一頁完成前對這九問

這頁要讓人做什麼？為什麼是這個版面？下一步去哪？中文是否為主？英文是否只是副標？字體是否按本規約？顏色有沒有意思？能按的是否真能按？未完成是否標成準備中或課文未寫？

## 14. 一句話

不要把資訊放進容器。把資訊變成可以走進去的空間。

人應覺得：我正在走進一個世界。而不是：我正在查一個資料庫。

氣質：溫暖、人文、安靜、有深度、想探索、可信、有信仰的溫度。不像考試、不像軟體儀表板、不像遊戲、不像百科條目堆疊。
