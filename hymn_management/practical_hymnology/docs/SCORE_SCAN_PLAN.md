# 樂以載道 · 譜圖掃描規劃

圖夾：`hymn_management/hymn/image_hymn`（約 2907 個圖檔）。  
`hymn/default.htm` 是手做曲目索引，不改、不覆蓋。分析表放在旁邊。

聖詩分析（`resource_selector.html#lenses`）只讀狀態為「選用」的列。未選用的只顯示「待核對」。

## 五步

1. **檔名表。** 從圖檔名列出編號、歌名、調名、圖檔路徑，並對上曲庫原頁。這一層不看圖。
2. **歌詞用網頁。** 詞從曲庫 `.htm` 或已有歌詞索引併入，不從圖重新認詞。
3. **先試約 20 首。** 用能看圖的方式讀完該首全部頁，填調號、拍號、節奏、曲式、譜上印出的和弦。狀態寫「候選」。沒印出來的和弦不配。看不清寫「待核對」。
4. **人對過才進聖詩分析。** 打開譜核對後，把狀態改成「選用」。聖詩分析才顯示這些欄。
5. **其餘分批。** 兩千多首沿同一條路做，不一次當成完成，也不設無人值守掃完全夾。
