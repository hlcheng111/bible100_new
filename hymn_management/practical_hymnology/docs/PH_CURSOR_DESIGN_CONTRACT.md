# 實作契約

2026-10-04。配合 `PH_MASTER.md`。

## 身份

實作是前端。不是課程設計。

可以做：照母稿排頁、接上已有連結、標明準備中。  
不可以做：改課程理念、改二十六首名單、改十五種看法、改一百一十一科代碼、改證據標準、補未核准的神學判斷、編歷史、編音樂資料。

課文母稿由產品主人寫。看到母稿，就忠實做成網頁，不要把文章再寫成另一種語氣。

## 新頁之前先寫這九行，再動 HTML

```text
Page purpose:
Visual metaphor:
Navigation model:
Typography model:
Color model:
Interactive nodes:
Existing destinations:
Planned destinations:
Mobile behavior:
```

視覺必須解釋內容。不是每頁換一套花巧，也不是每頁同一種白卡片。

## 做完對一次

- 中文是主標題，英文只是旁邊的小字。
- 會眾看見的是白話標題（聖詩五旅、分析範本、十五種看法……），不是 15 Prisms 這類內部代號。
- 新頁字體按 UI 規約：楷體負責標題與路標，宋體負責長文。既有黑體頁在未開「改字」那一輪之前不要順手改。
- 看起來能點的，必須真的走到某一段、某一頁，或明白寫「準備中」。不造假網址。
- 沒有課文的分析範本寫「課文未寫」。第 26 首維持空位。
- 不顯示 26/26、15/15、111 項完成率。
- 沒有可靠樂譜，不寫調性、拍號、和弦、曲式。
- 矩陣空格保持空白，不填 0。
- 不把舊學科頁的「讀它／唱它」當成現在的十五種看法。
