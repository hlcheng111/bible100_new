# 課頁骨架

2026-10-04 入檔。這是以後二十六首課頁的母型。C01 已按這個骨架做了第一頁。奇異恩典現有草稿不要為了套這個骨架而改寫。

## 固定骨架，每首不同的舞台

結構一致，氣質可以不同。不要二十六頁長成同一個網站，也不要二十六頁各做一套無關的設計。

骨架順序：

1. 回到學習地圖。編號、中文歌名、英文副標、一句這首歌今天要問的話。
2. 聖詩五旅的五個名字（遇見、看見、追問、查證、回來）放在頁邊，只作定位。正文若已有母稿分段，就照母稿走，不把正文收成這五站。
3. 先遇見：歌詞、聲音、有證據才放譜。
4. 看見什麼：只放這一首真的要看的層（文本、聖經、音樂、歷史……）。
5. 一個值得追問的問題。
6. 查證：來源、證據層次、版本。不知道就停。
7. 回到歌：再讀、再聽、再唱。
8. 這一首打開哪些看法。只列有關係的。
9. 它可以走向哪些學科。山還在，今天不必走完。
10. 研究工具：只連已經存在的工作台或來源，不造新工具頁。
11. 下一步：另一首，或換你來。

## 共用骨架，每首一個舞台

七十份共通，三十份只屬於這一首。不要二十六套網站，也不要二十六頁長得一模一樣。

目錄五個名字，二十六首共用：遇見、看見、追問、查證、回來。

五站只作旁邊的定位，不把正文收成五段。C01 的正文是母稿二十四段，次序不改。
