## 首屏

留白要大。不要作者、年份、曲調。那些等到第八、第九段。

由上到下：

1. C01
2. 普天之下萬民萬族（楷體，最大）
3. All People That on Earth Do Dwell（英文，小）
4. 誰正在唱？
5. 五個小圈，線匯到中間一個點。點下只寫「我們」。

這是匯聚，不是裝飾圖。圈上不寫人名、年份、曲名、詩篇號。

## 二十四段的畫面語言

每一段仍先完整放上母稿原文。下面的圖是原文的形狀，不是改寫。

第六段的五步是這首歌的形成路線。它不是旁邊那五個學習站。兩套不要混名，也不要合併。

| 段 | 畫面 | 不要做成 |
|---|---|---|
| 1 | 大留白。問句「誰正在唱？」單獨大。其餘句子在下面，小聲 | 介紹卡 |
| 2 | 兩拍：先唱一次，再唱一次。中間一條橫線 | 播放器 |
| 3 | 整幅只剩巨大楷體 All people。其下才是「不是 I sing to the Lord」，再是「而是」，再一次 All people。然後散開四個身份：一個人、一位詩班員、一位牧師、一位音樂家。最後回到 All people | 一張發現卡 |
| 4 | 句中的 All 與 people 可圈。兩個按鈕：「圈出 All」「圈出 people」。點了只加圈，不改句子 | 測驗 |
| 5 | 一條動詞流：Sing → Serve → Praise → Come → Rejoice。向外拉開，不是五格 | 五張卡 |
| 6 | 一條直路，五步向下：Psalm 100 → 聖經的詩 → Kethe 的格律詩 → 可以唱的英文聖詩 → 會眾共同歌唱 | 與第七段併成一圖 |
| 7 | 另一條直路，三步：Scripture → Hymn → Congregation | 與第六段併成一圖 |

## 證據階梯

由下往上，三層仍在同一區：

1. 比較有把握知道的。保留「1561 年」。

3. 仍然可以問的。保留問句，以及「研究問題不是失敗，是下一條路。」
