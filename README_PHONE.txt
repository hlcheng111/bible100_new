Bible100 手機／平板試用包
========================

1. 將整個資料夾解壓到手機（例如 Download/bible100_Slim）。

2. 用檔案管理器找到 index.html，點開。
   - Android：Chrome 或「HTML 檢視器」
   - iPhone：檔案 App → 點 index.html → 用 Safari 開啟

3. 不必輸入 localhost；與 PC 一樣是「點 index 進站」。

限制
----
- 精簡包不含完整 languages／全詩歌庫，僅模組入口與示例。
- 上線到您的網站（https）後，可「加到主畫面」當 Web App，體驗較完整。

PC 說明見 README_PC_TRIAL.md
