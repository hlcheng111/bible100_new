# translation_system

**本目錄為全站翻譯／抽取／覆寫管線之一部分，請勿刪除。**

- `core/`：產生、抽取、雲端同步等邏輯。
- `data/`：`auto_translations`、`manual_overrides` 等 JSON。
- `ui/`：管理介面與使用說明 HTML。
- `config/settings.json`、`config/languages.json`：與根目錄 `config/languages.json` 分工不同；變更前請對照 `languages/` 大模組之實際載入方式。

詳見歷史報告：`docs/reports/SITE_FULL_AUDIT_LATEST.md` 內 `translation_system` 一節。
