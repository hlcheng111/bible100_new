如何加入新網站或新難題

方法一：僅顯示新網站入口（最簡單，無需跑腳本）

適用於：只想在「二層：來源」選單中加入新網站連結，不需要可搜尋的難題目錄。

  1. 開啟 qna_nav_config.js
  2. 在 sources 陣列中加入一筆，例如：
{
  "id": "新來源id",
  "label": "顯示名稱",
  "category": "A",   // A=聖經書卷, B=神學教義, C=信徒教會
  "sidebar": "qna_list_auto.htm",  // 或專屬的 qna_list_xxx.htm
  "landing": "https://新網站網址/",
  "lang": ["zh"],    // 或 ["en","zh"]
  "zh_url": "https://中文版網址/"  // 若有中文版
}

完成後重新整理頁面即可看到新網站。

方法二：加入可搜尋的難題目錄（需執行腳本）

適用於：希望新網站的難題出現在左側欄，可被搜尋。

  1. 在 qna02.htm 加入區塊（建議加在 </body> 前）：
<hr>
<h2>新網站名稱</h2>
<p>
<a href="https://新網站/題目1.htm">題目1</a><br>
<a href="https://新網站/題目2.htm">題目2</a><br>
...
</p>

注意：<h2> 內的文字必須與 links_merged.json 的某個 sources[].label 完全一致，否則解析器會略過。

  1. 執行腳本（在專案根目錄）：
python scripts/parse_qna02_to_json.py
python scripts/build_qna_list.py
  1. 重新整理瀏覽器，即可看到新難題出現在目錄中。

方法三：手動編輯 qna_list_auto.htm（不建議）

可直接編輯 qna_list_auto.htm，但下次執行 build_qna_list.py 時會被覆蓋。

僅適用於：暫時測試，或確定不再執行 build 腳本。

📝 分類對照

  • A（聖經書卷難題）：經文疑難、矛盾、背景等
  • B（神學教義難題）：辯道、護教、神學問答
  • C（信徒教會難題）：信仰、生活、教會實務

💡 提示

  • 若新網站有專屬的目錄頁（如 qna_list_chineseapologetics.htm），可在 sidebar 欄位指定該檔案
  • 若沒有專屬目錄頁，使用 qna_list_auto.htm 即可（會顯示所有來源）
  • 支援多語言的網站，可設定 lang: ["en","zh"] 並提供 zh_url，系統會自動顯示語言選譯連結
