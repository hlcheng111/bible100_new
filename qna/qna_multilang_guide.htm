🚀 快速開始 / Quick Start

1找到翻譯工具 / Find Translation Tool

在每個頁面的右上角，您會看到一個翻譯工具框（顯示「選擇語言」或「Select Language」）。

In the top right corner of each page, you will see a translation tool box (showing "選擇語言" or "Select Language").

📌 翻譯工具位置 / Translation Tool Location

[選擇語言 ▼]

2選擇您的語言 / Select Your Language

點擊翻譯工具框，從下拉選單中選擇您想要的語言：

Click the translation tool box and select your preferred language from the dropdown menu:

  • 中文 (Chinese) - 繁體中文或簡體中文
  • English - 英文
  • 日本語 (Japanese) - 日文
  • 한국어 (Korean) - 韓文
  • Tiếng Việt (Vietnamese) - 越南文
  • Bahasa Indonesia - 印尼文

3自動翻譯 / Automatic Translation

選擇語言後，整個頁面會自動翻譯成您選擇的語言。翻譯是即時的，無需重新載入頁面。

After selecting a language, the entire page will be automatically translated into your chosen language. Translation is instant and does not require reloading the page.

4切換語言 / Switch Languages

您可以隨時切換到其他語言。只需再次點擊翻譯工具框，選擇另一個語言即可。

You can switch to another language at any time. Simply click the translation tool box again and select another language.

💡 使用技巧 / Tips

✅ 最佳實踐 / Best Practices

  • 翻譯品質：Google 翻譯提供良好的翻譯品質，但對於專業術語（如神學名詞），建議參考原文以確保準確性。
  • Translation Quality：Google Translate provides good translation quality, but for specialized terms (such as theological terms), it is recommended to refer to the original text to ensure accuracy.
  • 書卷名稱：翻譯後的書卷名稱可能與您熟悉的版本不同（例如「創世記」可能被翻譯為「Genesis」）。這是正常的。
  • Book Names：Translated book names may differ from the version you are familiar with (e.g., "創世記" may be translated as "Genesis"). This is normal.
  • 連結功能：翻譯後，所有連結和功能仍然正常運作。
  • Link Functions：After translation, all links and functions continue to work normally.

⚠️ 注意事項 / Important Notes

  • 翻譯限制：翻譯工具僅翻譯頁面上的文字內容，無法翻譯圖片中的文字。
  • Translation Limitations：The translation tool only translates text content on the page and cannot translate text in images.
  • iframe 內容：如果右側顯示的是外部網站（iframe），該網站的內容不會自動翻譯。您需要點擊該網站內的翻譯工具（如果有的話）。
  • iframe Content：If the right side displays an external website (iframe), the content of that website will not be automatically translated. You need to click the translation tool within that website (if available).
