# Bible100 · 合作默契（Collaboration SKILL）

> 給**產品主人 ↔ AI**對話用。不是 Cursor 禁令清單；工程細則見 `docs/governance/*` 與 `.cursor/rules/*`。

---

## 一、宗（萬變不離）

**Bible100 為什麼存在：** 教聖經、出教材（100 步／四寶）；服務中文老師與四語小白，**能用、敢用、愛用**。

| 層 | 使命 |
|----|------|
| 核心 | 教材、跑道讀經、課件 |
| 輔助 | 研讀、難題、教會、學校、AI 備課——服務「讀好、實踐、建造」 |
| AI | 草稿助手；**須人審**；不取代牧者／老師 |

**體驗志向：** 易用肯用 → 好用愛用 → 淺入深（學生可長成老師）。

**四身份口訣：** 地圖穩 · 做事深 · 出國明 · 編號追。

---

## 二、學生 → 老師（進程門票）

| 級別 | 誰 | 入口 | 不做什麼 |
|------|-----|------|----------|
| L1 跟讀 | 新信徒 | 聖經跑道：尋寶地圖 → 賽道 → 讀經 → 打卡 | 不預設進總站六模組 |
| L2 有疑問 | 讀了一陣 | 讀完頁 **2 卡**：D 問 / E 深讀 | 不鏈備課工作台、測驗 demo |
| L3 帶人 | 小組長 | 導讀站、難題 Q&A（帶經文） | 不把 demo 當成品 |
| L4 備課 | 主日學老師 | 總站 **AI 輔助 → 備課創作** | 跑道讀者不應被丟進這裡 |

**INDEX（`index_v5`）定位：** 資深同工／工程地圖；**會友主路在跑道**，不是頂欄六選一。

## 三、兩種站殼：綜合 Hub vs 獨立 Standalone

| | Hub 總站 | Standalone 模組 |
|--|----------|-----------------|
| 入口 | `index_v5.html` | 各模組 `…/index.html` |
| 結構 | 頂欄 + `sidebarFrame` + `contentFrame` | 模組自帶雙欄殼 |
| 用途 | 換大模組、跨模導覽 | 可單獨上雲、雙擊、USB |
| 鐵律 | 右欄不嵌「殼中殼」同名 `contentFrame` | Hub 載入**內容頁**，非模組殼 |

**導覽三層心智：** 選國（頂欄1）→ 看地圖（左欄）→ 做事（右欄）。換模組必須明示，不可 silent 換側欄。

**綜合與獨立並存：** 模組可獨立運行；進 Hub 時用 `data-b100-nav` 契約（`content` / `module`）。改一邊須想另一邊是否仍通。

## 四、模組地圖（頂欄1 精簡）

| 模組 | 小白一句 | 與跑道關係 |
|------|----------|------------|
| 教材與培訓 | 開課、課件 | 核心教材 |
| 聖經研讀 | 釋經、逐字、綜合解讀 | 跑道、interlinear 掛此 |
| 聖經難題 | 題庫問答 | D 區可鏈入，非第一站 |
| 教會事工 | 點名、主日學、CRM | 輔助實踐 |
| 學校管理 | 學籍課程 | 輔助體制 |
| AI 輔助 | 備課、Prompt、Lab | **老師用**；跑道不預設進 |

## 五、技術底線（人話）

| 主題 | 約定 |
|------|------|
| **驗收真相** | 成品以 `file:///…/index_v5.html` Ctrl+F5 為準；HTTP／雲端不一致時以 file:// 修 |
| **資料** | `data/` 本機聖經庫，不進 Git；clone 後自行還原 |
| **經節** | 跑道 `bible_reader.db` = 節級 SSOT；逐字工作台 = 詞卡 overlay，非第二套經庫 |
| **逐字對照** | 無 Key 時「未譯」不填原文；任意新句≠自動通順譯；V1 越／印 |
| **敏感資料** | 問卷、牧養筆記、Smart Ministry raw 預設只留本機 |
| **一波一主題** | 禁止同輪大改三模組 IA |

## 六、PC 與上雲

| 角色 | 路徑 |
|------|------|
| 開發唯一源 | `bible100_new/` |
| FTP 包 | `bible100_new_2/` → FileZilla → bible100.lovestoblog.com |
| 流程 | 改源 →（若動 config）`generate_config_embedded.js` → sync → FTP ZIP |
| 原則 | **不在 mirror 手改**；雲端追本機，不反向 |

上雲賣的是**主路徑閉環**；demo 可上雲但須**降權標示**，不從跑道主路默認鏈過去。

---

## 七、改新不忘舊（每輪必帶）

用戶常擔心整合後丟原型優點（如 interlinear V6 UI）。每輪請鎖四行：

```
【場景】file:// / http://127.0.0.1:8080 / 雲端 URL
【角色】會友 / 備課老師 / 工程驗收
【本輪唯一交付】一句話、可點驗收
【不可丟】1～3 項舊版必留（UI／流程／文案）
```

**刻意不做**一行，避免 scope 膨脹。

## 八、開場 Prompt（複製用）

### P0 · 通用
```
依 bible100-collaboration 默契：小白+專家；結論先；一波一主題。
驗收：file:///C:/Users/hlche/.cursor/bible100_new/index_v5.html
本輪只做：________。不可丟：________。
```

### P1 · 模組巡查（另觸發 `bible100-module-audit`）
```
雙視角巡查：________。先評分 1–5 + Top3 + 下一刀；不要先大改。
```

### P2 · 授權執行
```
按下一刀執行；做到可驗收再交付。≤5 條改動 + 頂/左/右 + 未做一行。
```

### P3 · 降維
```
頭暈／太複雜。只留一個入口、一個動作。
```

### P5 · 上雲
```
sync 到 bible100_new_2 + FTP ZIP 路徑；我只搬運。
```

### P7 · 參考下文
```
以下當素材：綜合後給**一個**推薦方案，勿整篇複述。我說執行再改檔。
```
