# Bible100 模块统一开发标准\n\n## 🎯 目标\n基于语言切换危机的经验教训，制定统一的模块开发标准，避免"架床叠屋，乱在一起"的问题。\n\n## 📁 模块文件结构标准\n\n### 必需文件\n每个模块必须包含以下标准文件：\n```\nmodule_name/\n├── sidebar.html          # 专门的sidebar文件（必需）\n├── dashboard.html        # 模块主页面（必需）\n├── index.html           # 独立运行页面（可选）\n└── [功能页面].html       # 各功能页面\n```\n\n### 文件作用说明\n- **sidebar.html**: 纯粹的sidebar内容，用于加载到主页面的sidebarFrame\n- **dashboard.html**: 模块的主要内容页面，用于加载到主页面的contentFrame\n- **index.html**: 完整的独立页面（包含自己的sidebar和content），用于独立运行\n\n## 🎨 CSS样式统一标准\n\n### 基础样式模板\n所有sidebar.html必须使用统一的基础样式：\n\n```css\nbody, html { \n  margin: 0; \n  padding: 0; \n  height: 100%; \n  font-family: "Microsoft YaHei", "Segoe UI", Tahoma, Geneva, Verdana, sans-serif; \n  background: #eef6ff; \n  color: #333; \n  font-size: 10px;\n  -webkit-text-size-adjust: 100%;\n  -ms-text-size-adjust: 100%;\n  text-size-adjust: 100%;\n}\n\n#container { \n  height: 100%; \n  overflow-y: auto; \n  padding: 3px 5px;\n}\n\nnav#sidebar { \n  width: 100%; \n  background: #eef6ff; \n  overflow-y: auto; \n  padding: 3px 5px;\n}\n\n/* 导航分类 */\n.course-category {\n  margin-bottom: 12px;\n}\n\n.course-category h3 {\n  color: #004d99;\n  font-size: 0.9rem;\n  margin-bottom: 6px;\n  padding: 4px 6px;\n  background: #d4e6f7;\n  border-radius: 3px;\n  cursor: pointer;\n}\n\n.course-category h3:hover {\n  background: #c0d9f0;\n}\n\n/* 导航列表 */\n.course-list {\n  list-style: none;\n  padding: 0;\n  margin: 0;\n  display: none;\n}\n\n.course-list.active {\n  display: block;\n}\n\n.course-list a {\n  display: block;\n  padding: 4px 8px;\n  color: #0066cc;\n  text-decoration: none;\n  background: #f8fbff;\n  border-radius: 2px;\n  font-size: 9px;\n  transition: all 0.2s ease;\n}\n\n.course-list a:hover {\n  background: #e6f3ff;\n  color: #004d99;\n  transform: translateX(2px);\n}\n\n/* 底部导航 */\n.bottom-nav {\n  margin-top: 15px;\n  padding-top: 10px;\n  border-top: 1px solid #ccc;\n}\n\n.bottom-nav a {\n  display: inline-block;\n  margin: 2px 4px 2px 0;\n  padding: 3px 6px;\n  background: #2aa5ff;\n  color: white;\n  text-decoration: none;\n  border-radius: 2px;\n  font-size: 9px;\n}\n\n.bottom-nav a:hover {\n  background: #0077cc;\n}\n```\n\n### 特殊主题变体\n- **儿童版 (CH)**: 可使用橙色主题 (#ff6b35, #fff5e6)\n- **高级版 (AD)**: 可使用深色主题 (#1a1a2e, #4fc3f7)\n- **其他模块**: 统一使用蓝色主题 (#004d99, #eef6ff)\n\n## 🔗 链接和导航标准\n\n### iframe目标设置\n- 所有sidebar中的链接必须使用 `target="contentFrame"`\n- 返回主页链接使用 `target="_parent"`\n\n### JavaScript函数标准\n每个sidebar.html必须包含标准的菜单切换函数：\n\n```javascript\nfunction toggleCategory(categoryId) {\n  var category = document.getElementById(categoryId);\n  if (category) {\n    if (category.style.display === 'none' || !category.classList.contains('active')) {\n      category.style.display = 'block';\n      category.classList.add('active');\n    } else {\n      category.style.display = 'none';\n      category.classList.remove('active');\n    }\n  }\n}\n\n// 默认展开某些菜单\ndocument.addEventListener('DOMContentLoaded', function() {\n  // 根据需要展开默认菜单\n});\n```\n\n## 🏗️ 主页面集成标准\n\n### index.html中的模块函数\n每个模块在主页面index.html中必须有对应的函数：\n\n```javascript\nfunction openModuleName() {\n  document.getElementById('sidebarFrame').src = 'module_name/sidebar.html?v=' + Date.now();\n  document.getElementById('contentFrame').src = 'module_name/dashboard.html?v=' + Date.now();\n}\n```\n\n### 按钮样式统一\n主页面topbar中的模块按钮应使用统一样式：\n\n```css\n.module-link {\n  display: inline-block;\n  margin: 0 10px;\n  padding: 8px 16px;\n  background: #667eea;\n  color: #fff;\n  text-decoration: none;\n  border-radius: 20px;\n  font-weight: bold;\n  font-size: 10px;\n  transition: all 0.3s ease;\n}\n\n.module-link:hover {\n  background: #5a6fd8;\n  transform: translateY(-2px);\n  box-shadow: 0 4px 12px rgba(102, 126, 234, 0.3);\n}\n```\n\n## 🚫 避免的问题\n\n### CSS冲突防范\n1. **不要在sidebar.html中使用全局CSS**，避免影响父页面\n2. **不要使用绝对定位**，避免布局冲突\n3. **使用相对单位**，确保响应式兼容\n\n### 文件结构混乱防范\n1. **不要加载完整页面到sidebarFrame**\n2. **不要在sidebar中包含完整的HTML结构**\n3. **不要重复定义相同的CSS规则**\n\n### JavaScript冲突防范\n1. **使用模块特定的函数名**\n2. **避免全局变量冲突**\n3. **确保事件监听器正确绑定**\n\n## ✅ 检查清单\n\n### 新模块创建时\n-
