# 聖經研讀 - 使用說明（小白友善版）

## 🎯 目標：一開啟就看到真經文

### 方式一：雙擊啟動（推薦，完整功能）

1. **雙擊** 專案根目錄的 **`啟動聖經研讀.bat`**
2. 等待約 2 秒，瀏覽器會自動開啟
3. 預設即顯示 **創世記第1章** 經文
4. 詞典、搜尋、對照模式等完整功能皆可用

### 方式二：直接開啟 HTML（經文閱讀可用）

1. 雙擊 `bible_study/index.html` 或從主站點「聖經研讀」
2. 會立即顯示經文閱讀器（創世記第1章）
3. 若經文未顯示或載入較慢，可點擊頂部提示中的 **輕量版** 連結
4. 詞典、搜尋等需載入外部資料的功能，請改用**方式一**

---

## 📖 預設顯示

- **主站**（index.html）→ 點「聖經研讀」→ 直接顯示經文閱讀器
- **研讀模組**（bible_study/index.html）→ 一開啟即顯示經文閱讀器

兩者皆預設載入 **和合本修訂版 · 創世記第1章**。

---

## 🛠️ 疑難排解

| 狀況 | 建議 |
|------|------|
| 經文區空白 | 等候 3–5 秒（大檔案需解析）；或點頂部「輕量版」 |
| 詞典 / 搜尋無結果 | 請用 **啟動聖經研讀.bat** 以 HTTP 開啟 |
| 找不到 .bat 檔 | 位於 `bible100_new` 根目錄，檔名：`啟動聖經研讀.bat` |
| 雙擊 .bat 後無反應 | 請先安裝 Python 3：https://www.python.org/downloads/ |
