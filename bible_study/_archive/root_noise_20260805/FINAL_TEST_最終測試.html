🛠️ 手動清除緩存指南

Chrome / Edge：

  1. 按 Ctrl + Shift + Delete
  2. 選擇「時間範圍」→「不限時間」
  3. 勾選「快取圖片和檔案」
  4. 點擊「清除資料」

Firefox：

  1. 按 Ctrl + Shift + Delete
  2. 選擇「時間範圍」→「全部」
  3. 勾選「快取」
  4. 點擊「立刻清除」

或者使用隱私模式：

  • Chrome / Edge：按 Ctrl + Shift + N
  • Firefox：按 Ctrl + Shift + P
