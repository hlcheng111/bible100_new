🔧 數據庫維護工具 - 檢查清單

請用 HTTP 開啟本專案（例如 VS Code Live Server 或 python -m http.server）， 再依序點下面連結檢查。直接用 file:// 開啟時，工具無法用 fetch 讀取 .db。
  1. 結構分析 開啟 db_analyzer.html
    → 應顯示「準備開始分析...」，點「開始分析數據庫」後會嘗試載入 data/cj 或 data/bibles 的 .db；有 .db 則顯示表結構與樣本。
  2. 診斷 開啟 db_diagnosis.html
    → 頁面載入即自動診斷，應顯示 SQLite 載入、表列表與結構（或「未找到可用的 .db」）。
  3. 轉 JSON 開啟 db_to_json_converter.html
    → 點「開始轉換為 JSON」，成功後「下載 JSON」按鈕會可點，可下載導出的 JSON。
