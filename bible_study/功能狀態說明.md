# 聖經研讀中心 - 功能狀態說明

> 更新：2025-03

## 一、譯本對照（📑 左右並排）

**F5 還原**：已修復。切換到對照模式後，會將 `frame=parallel_mode_v3.html`（舊連結 `parallel_mode_v2.html` 會轉址）寫入 URL，並存入 sessionStorage。按 F5 會還原到對照模式。

若仍無法還原，請確認：
- 直接開啟 `http://127.0.0.1:8080/bible_study/`（非從總 index 的 iframe 進入）
- 或使用 `http://127.0.0.1:8080/bible_study/?frame=parallel_mode_v3.html` 直接進入（`v2` 仍會轉址至 v3）

---

## 二、聖經閱讀（📖 和合本/KJV/NIV）

**版本來源**：
- **parallel_mode_v3**（正式）；`parallel_mode_v2.html` 僅保留轉址。對照頁版本選項以 v3 為準。
- 實際載入依賴 `BibleEngine` / `universalDataLoader` 的 JSON 檔
- 若顯示「已載入 0」：表示 `data/bibles/` 下對應 JSON 不存在或路徑錯誤

**目前有效**：和合本修訂版(cuvr)、NIV（若 JSON 存在）
**可能失效**：和合本(cuv)、KJV、信望愛(faith) — 需確認 `data/bibles/*.json` 是否存在

**KJV(附原文號)**：若曾出現，可能來自其他頁面（如 refined_bible_reader、original_text）或舊版；對照主路徑以 parallel_mode_v3 為準。

---

## 三、全文搜尋（🔍 Search）

**search_reader.html** 功能：
- 輸入關鍵詞 → 搜尋 `data/bibles/` 下的 JSON（信望愛、和合本、KJV、NIV）
- 「全部版本 | 信望愛 | 和合本 | KJV | NIV」：可切換搜尋範圍，**有功能**
- 若顯示「沒有找到結果」：可能原因
  1. 關鍵詞在該版本中不存在（如 "holy" 在中文版不會出現）
  2. JSON 檔缺失或路徑錯誤（需用「啟動聖經研讀.bat」啟動）
  3. 檔名編碼差異（如 信望爱 vs 信望愛）

**底部工具列**（📖閱讀🔍搜索📝筆記⭐收藏🌍原文💬）：
- 📖閱讀、🔍搜索：有對應功能
- 📝筆記、⭐收藏、🌍原文、💬註解：**目前為佔位**，尚未實作

**與詩歌管理搜尋的差異**：
- 詩歌管理：搜尋歌本、歌名、歌詞等
- 聖經全文搜尋：搜尋經文內容（需 JSON 資料）

## 五、原定設計方向（摘要）

1. **閱讀**：左經文、右註釋，可切換版本
2. **研經**：綜合解讀（CMC iframe）為主，本地註釋為輔
3. **對照**：多譯本並排，方便比較
4. **搜尋**：全文搜尋經文，可選版本
5. **詞典 / 串珠**：需整合信望愛或自建資料

---

## 六、建議檢查項目

1. 執行「啟動聖經研讀.bat」確保本地伺服器與資料路徑正確
2. 確認 `data/bibles/` 下有：`信望爱(和合本).json`、`和合本.json`、`KJV.json`、`NIV.json`、`和合本修訂版.json`
3. 搜尋時：中文關鍵詞選「信望愛」或「和合本」；英文選「KJV」或「NIV」
