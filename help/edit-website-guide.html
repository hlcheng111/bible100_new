如何編修本站網頁

本指南說明如何使用「HTML 所見即所得編輯器」編修 Bible100 站內網頁內容，包含插入圖片、影片、連結等。

📝 開啟 HTML 編輯器

一、什麼是 HTML 所見即所得編輯器？

所見即所得（WYSIWYG）：在編輯器中看到的版面，就是網頁實際顯示的樣子。無需手寫 HTML 標籤，即可編排文字、插入圖片與影片。

本站採用 TinyMCE 編輯器，可從頂欄「工具 ▾」→「HTML 編輯器」或直接開啟 tools/html_editor.html 使用。

二、基本操作

1. 開啟編輯器

  1. 從頂欄「工具 ▾」→「HTML 編輯器」，或開啟 tools/html_editor.html
  2. 在編輯區輸入或貼上內容

2. 插入圖片

  1. 點工具列「插入／編輯圖片」圖示
  2. 輸入圖片路徑（相對路徑），例如：
    • ../languages/images/landing_infographic_flow.png（共用圖片）
    • ../languages/media/images/photo.jpg（媒體庫）
    • ../../media/images/y_nghia_so_40_trong_kinh_thanh.jpg（從章節頁往上兩層到語文 media/images，如 vi）
  3. 圖片需先放入對應資料夾，路徑才會正確

3. 插入 YouTube 影片

  1. 點工具列「插入／編輯媒體」圖示
  2. 貼上 YouTube 網址，例如 https://www.youtube.com/watch?v=xxxxx
  3. 編輯器會自動轉成嵌入 iframe

4. 插入連結

選取文字後，點「插入／編輯連結」，輸入目標網址。

5. 預覽與下載

  • 預覽：點「預覽」按鈕，在下方 iframe 檢視效果
  • 下載 HTML：點「下載 HTML」，取得 .html 檔案，可複製內容貼回實際頁面

三、媒體路徑說明

本站媒體存放位置：

類型路徑
共用圖片languages/images/（image_NT、image_OT、whole_book.files 等）
共用媒體languages/media/images/、video/、audio/、pdf/、ppt/
語文專屬languages/{語文}/media/images/ 等（cn, en, vi, id, ch, ad, kh, lo, my）

從 tools/html_editor.html 引用時，路徑需以 ../languages/ 開頭。

新媒體加入程序

  1. 將檔案放入對應夾：語文專屬 → languages/{語文}/media/images/；共用 → languages/media/images/
  2. 檔名需自行命名（無自動前綴），建議格式如 OT1_ch01_img001.jpg
  3. 在網頁中引用：章節頁用 ../../media/images/檔名（語文專屬）或 ../../../media/images/子夾/檔名（共用）

詳見 languages/MEDIA_STRUCTURE.md。

四、注意事項

  • 本編輯器不直接寫入檔案：編修後需「下載 HTML」，再手動貼回對應 .html 檔，或由總編輯協助更新。
  • 備份：修改前請先備份原檔，或使用 Git 版本控制。
  • 編碼：儲存時請使用 UTF-8 編碼，避免中文亂碼。
  • 路徑：圖片、影片路徑請使用相對路徑，以利不同環境部署。
