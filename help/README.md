# help／全站解說與試用頁

本目錄為 **Bible100 跨模組說明、導覽地圖、同工手冊與試用入口** 的集合區；與各模組內「產品頁」分工如下：

- **留在 `help/`**：總覽、角色任務起點、專案狀態、工具地圖、編輯指南、課程手冊等。
- **歸各模組**：若某頁只服務單一模組且與該模組側欄強綁定，可遷入該模組並從此處留一條連結（遷移時請全域更新 href）。

## 常用入口

| 檔案 | 用途 |
|------|------|
| `docs-hub.html` | 文件導覽 |
| `tools-overview.html` | 工具總覽與模組連結 |
| `role-task-start.html` | 角色／任務起點 |
| `church_ministry_manual.html` | 教會事工手冊（含人員總覽等連結） |
| `site-sidebar-nav-map.html` | 側欄與路徑對照 |

路徑變更紀錄見 `docs/ROOT_REORG_2026-05.md`。
