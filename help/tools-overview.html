工具 ▾ 總覽 = 全站功能總入口。以下為各功能、類型、所屬模組與連結。

一、導航與 Dashboard

功能類型說明連結
會眾入口 Dashboard 跨模組 全站資料總檢視、人員統計、各模組摘要 church_ministry/congregation/index.html
目錄搜索 TOC & Search 跨模組 全站導覽與搜尋 nav_hub/index.html

二、編輯與貢獻

功能類型說明連結
HTML 編輯器 跨模組 所見即所得，編修 languages、qna 等 HTML tools/html_editor.html
詩歌編輯器 模組獨用 編輯詩歌標題、歌詞、作者、YouTube 等 hymn_management/hymn_editor.html
自訂頁面編輯器 模組獨用 會眾入口自訂區塊（文字、圖片、連結、活動） church_ministry/custom-page-editor.html
PPT 生成器 模組獨用 詩歌大字幕投影片、匯出 PDF hymn_management/ppt_generator.html

三、通用工具

功能類型說明連結

我的參與 聯合使用 輕量版：選身份、讀經進度、收藏、報名記錄 help/my-participation.html
