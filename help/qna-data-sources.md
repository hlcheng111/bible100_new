# QnA 聖經難題資料來源說明

## file:// 專用（無需 localhost）

若用 `file://` 開啟，分層載入版會因 `fetch` 無法讀取本地 JSON 而失敗。請改用：

- **`qna/index_file.html`**：左側單頁目錄（qna_list_auto.htm）＋右側 iframe，全部靜態，無需 HTTP 伺服器
- 或直接開 **`qna/qna_list_auto.htm`**：單頁可伸縮選單（約 4.3MB）

---

## 一、資料來源與「智能選用」

**沒有「智能選用」邏輯**。QnA 的題目與連結來自兩套資料的合併：

| 來源 | 檔案 | 說明 |
|------|------|------|
| **qna02.htm** | 手動編輯 | 恩泉、以斯拉百科、陳終道、葛培理（Billy Graham）等，有完整題目與原文連結 |
| **links_merged.json** | 爬蟲產生 | 葛培理、證道浸信會、以斯拉百科等，多為首頁／導覽連結，較少實際 Q&A 題目 |

合併時：若同一來源在兩邊都有，**qna02 會覆蓋 links_merged**。但若**標籤不同**，會變成兩個獨立來源。

## 二、各來源表現差異

- **qna02.htm** 有完整題目與連結
- 以斯拉百科 URL 若含 `?` 亂碼，build 會自動修復為正確路徑（如 `聖經難題/創-1`）

### 2.2 葛培理福音協會－Answers

目前有**兩個**來源：

| 標籤 | 分類 | 資料來源 | 內容 |
|------|------|----------|------|
| **葛培理福音協會－Answers** | 信徒教會難題 (C) | links_merged | 多為首頁／Topics 導覽，較少實際題目 |

**建議**：若要看實際 Q&A 內容，請點選 **「- Billy Graham Answers」**（在聖經書卷難題下）。

### 2.3 證道浸信會

- 來自 links_merged 爬蟲，多為首頁／導覽
- 若 qna02.htm 有手動整理的題目，可補入後重新 build

### 2.4 以斯拉百科－申命記～路得記

- 來自 links_merged，有 239 筆「未標註經文／主題」

- 以斯拉百科的「聖經難題」專區在 **「聖經難題 - 以斯拉百科網」**，品質較佳

## 三、英文站 iframe 空白

多數英文站（如 billygraham.org、gotquestions.org）設有 **X-Frame-Options**，禁止 iframe 嵌入。

**處理方式**：右鍵題目連結 → **「在新分頁開啟」**，即可看到原文。

---

## 四、與 qna02.htm 的差異

| 項目 | qna02.htm（原始） | 分層 sidebar（build 產出） |
|------|-------------------|----------------------------|
| 結構 | 單頁、手動編排 | Level 1→2→3 分層載入 |
| 資料 | 直接讀 HTML | 合併 qna02_tree + links_merged |
| 以斯拉 URL | 可能含亂碼 | build 時自動修復 |
| 葛培理 | 若標題為「Billy Graham」 | 可能出現兩個來源（見上表） |

**技術上**：build 會合併兩套資料，但**沒有**依品質或深度做「智能選用」。差異來自標籤對應與資料來源本身。

## 五、以斯拉百科 URL 與結構說明

### 5.1 聖經難題（舊約／新約）

- **正確格式**：`聖經難題-書卷名`（分類頁）或 `聖經難題/簡稱-N`（單篇，如 創-1、太-1）
- **錯誤格式**：`新約難題-馬太福音`、`舊約難題-創世記` → 會 404
- build 已自動將 新約難題／舊約難題 改為 聖經難題-書卷名

### 5.2 辯道護教

- 以斯拉百科的辯道護教區，每個子題（如「辯道學目標與內容」）是一個**分類頁**，列出多個 Q&A
- 站上沒有為每題設獨立 URL，故本系統的題目連結會指向該分類頁
- 點選後會到該主題頁，需在頁面內捲動找到對應題目
