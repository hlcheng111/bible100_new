① 國際專業理論背景 · Weihrich TOWS 交叉矩陣演算法白皮書

文獻出處：H. Weihrich (1982) TOWS Matrix — 在 SWOT 四象限基礎上，將內部因子（S/W）與外部因子（O/T）交叉耦合，產出 SO（增長）、ST（多元）、WO（轉變）、WT（防禦）四類可執行戰略，而非停在盤點。

A. 輸入權重（由 NCD 八維剛性轉換）

符號定義本系統取值教會神學詮釋
S_w內部優勢權重functional（NCD 結構維度）；empower 高於 S_w 時取均值神所量給的恩賜邊界與治理基建（量帶）
W_i內部劣勢強度NCD 最小因子得分（如 passion=2.0）罪性破口／組織僵化造成的靈性虧缺
W_intensity破口嚴重度(5 − W_i) ÷ 4破口越深，WO/WT 優先級越高
O_j外部機會權重工作坊 oClarity 均值或預設 3.8聖靈在社區已開展的福音浪潮
T_k外部威脅權重工作坊 tClarity 均值或預設 3.6世俗化、忙碌文化對教會的吞噬

B. 交叉耦合公式（calculateMatrix · Weihrich_TOWS_v1）

P_SO = (S_w/5) × (O_j/5) × 100    // 增長：用優勢抓機會
P_ST = (S_w/5) × (T_k/5) × 100  // 多元：S×T（T 不取反，對齊 swot_pack.js）
P_WO = (W_intensity) × (O_j/5) × 100 // 轉變：用機會修補破口
P_WT = (W_intensity) × (T_k/5) × 100 // 防禦：雙重壓力下排毒重組

Delta_Variance = S_w − W_i          // 結構−靈性落差（事工機器堂會指標）
conflict_SO_WO = |P_SO − P_WO| / 100 // 長執路線衝突係數
so_wo_tension = P_SO − P_WO         // 正值＝擴張派佔優；負值＝修補派應主導

牧養覆寫規則：若 Delta_Variance ≥ 2.0 且 W_i ≤ 2.5 → 強制主軸 = WO（靈性重燃優於 SO 擴張）

D. 神國眼光的四象限（非商業競爭語言）

  • S 優勢：不是「我們比別堂有錢」，而是神量給本堂獨特恩賜與托付的邊界（哪些事奉線是神驗證過的？）
  • W 劣勢：不是「規模小」，而是生命與架構上虧缺了神榮耀的破口 — 由 NCD 最小因子數學鎖定，禁止開會拍腦袋改 W
  • O 機會：不是「市場藍海」，而是聖靈已在社區開展、呼召教會加入的服事時機
  • T 威脅：不是「競爭對手」，而是盜賊來偷竊、殺害、毀壞的屬靈爭戰（約 10:10 的牧養框架）

資源配置原則：當 Delta_Variance 極大（結構強、靈性弱），神國邏輯要求先修補祭壇（WO/WT），再談擴張版圖（SO）。這不是保守，是依據最小因子法則的忠心。

示範鏈路（可驗證）：NCD functional=4.8、passion=2.0 → Delta_Variance=2.8 → 牧養覆寫 WO →「以社區外展為祭壇的靈性重燃計畫」。點 🔍 先看示範報告 查看真實 calculateMatrix() 輸出。

④ 長執桌 · 雙軌戰略平衡演算法溝通模型（Conflict Resolution）

完成 Tab ③ calculateMatrix() 後，此處顯示 NCD 鎖定、Delta_Variance 與 swot_contract 狀態。

雙軌平衡演算將在示範報告或工作坊提交後顯示 P_SO vs P_WO 與 conflict_SO_WO。

【模型 A：SO 激進擴張 × WO 內部排毒 — 雙軌平衡五步】

當 conflict_SO_WO > 0.15 或 Delta_Variance ≥ 2.0 時啟動此模型（長老要買堂／辦大活動 vs 牧者要停辦事工／深化門訓）。

  1. 數算代價（Cost Ledger）：在白板寫明 SO 路線的資源消耗（同工時數、預算、靈性透支風險）與 WO 路線的機會成本（延後擴張的落差）。禁止只喊異象不寫數字。
  2. 宣讀矩陣結果：由書記朗讀 Tab ③ 的 P_SO、P_WO、Delta_Variance — 讓數據成為第三見證，而非個人立場辯論。
  3. 牧養覆寫裁決：若 W_i ≤ 2.5 且 Delta_Variance ≥ 2.0，長執會正式決議「本季主軸 = WO」，SO 項目進入觀察名單而非立即執行。
  4. 90 天試驗期：WO 執行 6–8 週後檢核靈修指標（小組禱告出席、讀經完成率）— SMART-compliant 門檻由牧者與長執共同設定。
  5. 再評 SO：僅當 W_i 回升至 3.0 以上，才重新啟動 SO 擴張議程 — 這是「數算代價」後的合一，不是誰說服誰。

【五大降溫減震步驟 · 路加福音 14:31 數算代價】

  1. 步驟一：數算兵力與代價 — 在白板打印 P_SO 與 P_WO 及 Delta_Variance（Δ），讓數據成第三見證。
  2. 步驟二：結構為靈性築壇 — 引導長老將 S（制度、設備）資源傾注於修補 W（禱告、門訓），而非盲目 SO 擴張。
  3. 步驟三：休兵減速協議（WT 排毒） — 當 P_WT 排名前二，啟動 3 個月事工禁食期，停辦非核心聚會。
  4. 步驟四：90 天 SMART-compliant 試驗 — WO 主軸只推一個可檢核小改變。
  5. 步驟五：再評 SO — W_avg 回升至 3.0 以上才恢復擴張議程。

【模型 B：WT 屬靈排毒計畫 — 雙重壓力協議】

當 P_WT 排名前二且 T_k ≥ 3.5 時：W 破口與 T 威脅交會，系統建議啟動排毒協議而非加碼活動。

  • 第 1–2 週：長執帶頭公佈「事工暫停清單」（非核心新案凍結）+ 全教會禱告鏈啟動
  • 第 3–6 週：小組長培訓「衝突與和好」；禁止在疲憊中做重大人事決策
  • 第 7–8 週：重新執行 calculateMatrix()，比較 Delta_Variance 是否收斂 — 再決定是否恢復 SO

通用決談 5 題（長執退修會）

  1. 我們是否同意 NCD 鎖定的最小因子就是本年度 W 的核心？
  2. SO 擴張願景與 WO 修補需要，本季只能優先哪一個？

  5. 90 天後我們用什麼指標檢核 WO 是否生效？
