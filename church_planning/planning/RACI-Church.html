教會常見問題（RACI 幫你解決）

❌ 問題 1：大家都以為別人會做 → 沒人做
❌ 問題 2：兩個人都以為自己是負責 → 衝突
❌ 問題 3：牧者被塞太多事
❌ 問題 4：義工不知道界線

 

RACI 是什麼？

字母

名稱

定義

重點

R – Responsible（負責者）

執行任務的人

做事的人

可以多人

A – Accountable（當責者）

對結果負最終責任的人

最後拍板、批准

只能一個

C – Consulted（諮詢者）

需要被諮詢意見的人

雙向溝通

可多個

I – Informed（知會者）

需要被通知的人

單向通報

可多個

R 做事、A 負責、C 給意見、I 被通知。

　

 RACI 是屬靈操練，不只是管理工具

  • 不越權
    不缺位
    不推卸
    不搶功
    不混亂
    不黑箱

這就是合一。
這就是身體。
這就是屬靈成熟。

 

一. RACI 的操作流程

步驟 1：列出所有任務（橫軸）

例如：

  • 招待團隊排班
    主日流程
    兒童主日學教材準備
    敬拜團排練
    新朋友跟進
    小組長訓練

步驟 2：列出所有角色（縱軸）

例如：

  • 主任牧師
敬拜部長
兒童部長
行政同工
小組長
招待隊長

步驟 3：逐格填入 R / A / C / I

原則（來源一致）

  • 每個任務至少一個 R

  • 每個任務只能有一個 A（最重要）

  • C/I 視需要填

  • 若 A 不明 → 代表責任缺口

  • 若 A 有兩個 → 代表權責混亂

步驟 4：全體確認、公開透明

  • RACI 必須「溝通與確認」才能有效

步驟 5：每季檢討、更新

  • 因為教會人員流動、事工變化，RACI 需定期更新。


 

 三、RACI 的理想果效

多個來源一致指出 RACI 的果效包括：

1. 角色清晰，不再推卸責任

每個人知道自己該做什麼、不該做什麼。

2. 減少衝突、誤會、重複工作

因為責任清楚，溝通成本下降。

3. 提升效率與決策速度

A 是唯一拍板者 → 不再拖延。

4. 最佳化資源分配

避免某人被塞太多 R（來源明確指出）

5. 提升團隊合作與透明度

每個人都知道整個流程如何運作。

 ✦ 五、如何讓 RACI 在教會中「屬靈完整」？

聖經原則 × 管理工具 的方式整合。

1. R = 按恩賜服事（林前 12）

  • 負責者（R）不是「誰最閒」，而是：

  • 誰有神給的恩賜、負擔、能力。

2. A = 屬靈權柄（來 13:17）

A（當責者）必須是：

  • 神所設立的權柄
    對羊群負責的人
    願意為結果負責的人

A 不是權力，而是代禱與牧養的責任。

3. C = 智慧謀士（箴 15:22）

「不先商議，所謀無效；謀士眾多，所謀乃成。」
C（諮詢者）是教會中：

有經驗
有屬靈洞察
有專業知識的人。

4. I = 身體互相連結（弗 4:16）

I（知會者）代表：

教會是透明的、彼此連結的，不是黑箱作業。

5. RACI 是「合一」的操練（約 17）

RACI 不是管理工具而已，而是：

  • 彼此順服
    彼此尊重
    彼此配搭
    不越權、不缺位

這就是屬靈成熟的表現。

六、教會如何應用（從聖經學 RACI）

 
1. 牧者是 A，不是所有事的 R
			→ 摩西、使徒行傳 6
2. 義工是 R，不是旁觀者
			→ 尼希米記 3
3. 領袖要聽 C（謀士）
			→ 葉忒羅
4. 教會要透明（I）
			→ 初代教會
5. 避免越權（掃羅）
			→ A 與 R 不可混亂
6. 避免缺位（亞倫）
			→ 領袖要承擔責任
7. 避免分裂（哥林多）
			→ A 必須清楚

🟦 一、聖經中的「好例子」：角色清晰、權責分明（RACI 正面示範）

 

 ⭐ 例子 1：摩西 × 葉忒羅建議（出埃及記 18）

主題：分工、授權、當責

RACI 分析

 R（執行）：千夫長、百夫長、五十夫長、十夫長
A（當責）：摩西（最終判決者）
C（諮詢）：葉忒羅（給建議）
I（知會）：百姓（知道流程）

屬靈果效

摩西不再過勞
百姓不再排隊到崩潰
領袖被建立
整個國家更健康

教會應用

牧者是 A（當責），不是所有事的 R（執行）
義工、小組長、部門長是 R（執行）
顧問、長老、屬靈前輩是 C（諮詢）
會眾是 I（知會）
 

⭐ 例子 2：尼希米重建城牆（尼希米記 3）

主題：每段城牆都有負責人（R 清晰）

RACI 分析

R（執行）：各家族、各工匠、各區領袖
A（當責）：尼希米
C（諮詢）：祭司、長老
I（知會）：全城百姓

屬靈果效

每段城牆都有負責人 → 沒有重複、沒有缺口
工程快速完成
百姓同心合意

教會應用

每個事工（敬拜、招待、兒童、小組）都要有 明確負責人（R）
主任牧師或部長是 A
透明公開 → 合一
 

 ⭐ 例子 3：使徒行傳 6 章（七位執事）

主題：角色界線清楚，避免混亂

RACI 分析

R（執行）：七位執事（管理飯食）
A（當責）：使徒
C（諮詢）：全會眾（選出執事）
I（知會）：教會

屬靈果效

使徒專注禱告與道
執事專注實際服事
教會增長
沒有抱怨、沒有混亂

教會應用

牧者不應該做所有行政
執事／部長／義工要承擔 R
牧者保持 A（方向、屬靈責任）
 

 ⭐ 例子 4：耶穌差派十二門徒（馬太 10）

主題：任務清楚、權柄清楚、界線清楚

RACI 分析

R（執行）：十二門徒
A（當責）：耶穌
C（諮詢）：耶穌的教導
I（知會）：百姓、村莊

屬靈果效

門徒知道自己要做什麼
耶穌給清楚指示（界線、權柄、任務）
事工有效率、有果效
 

⭐ 例子 5：保羅的團隊（提摩太、提多、路加）

主題：團隊分工、按恩賜服事

RACI 分析

R（執行）：提摩太（牧養）、提多（整頓教會）、路加（記錄）
A（當責）：保羅
C（諮詢）：長老、同工
I（知會）：各教會

屬靈果效

每人按恩賜服事
保羅不需要做所有事
教會被建立、門徒被訓練
 

🟥 二、聖經中的「壞例子」：角色混亂、越權、缺位（RACI 反面教材）

 

❌ 例子 1：掃羅越權獻祭（撒上 13）

問題：A 與 R 混亂，越權

RACI 問題

R（執行）：祭司（撒母耳）
A（當責）：撒母耳
掃羅越權 → 把自己當成 R + A`

後果

神不喜悅
王位被廢
團隊混亂

教會應用

牧者不應越過別人的恩賜領域
義工不應越過屬靈權柄
A 與 R 必須清楚
 

 ❌ 例子 2：亞倫與金牛犢事件（出 32）

問題：A 缺位、R 無引導

RACI 問題

A（當責）缺位：亞倫沒有承擔領導責任
R（執行）混亂：百姓隨意行事
C/I 完全失效

後果

偶像崇拜
百姓犯罪
神的審判
　

教會應用

領袖若不承擔 A → 義工會混亂
沒有清楚方向 → 事工會偏離使命
 

 ❌ 例子 3：可拉黨叛變（民數記 16）

問題：不尊重 A（屬靈權柄）

RACI 問題

可拉想奪取 A（當責）
不尊重神所設立的權柄
破壞團隊秩序

後果

神審判
以色列震驚
團隊重新敬畏神

教會應用

不尊重 A → 團隊分裂
屬靈權柄是神設立的，不是人搶來的
 

 ❌ 例子 4：馬大與馬利亞（路 10）

問題：R 過重、A 不清楚、焦慮

RACI 問題

馬大承擔太多 R → 過勞
馬利亞專注在 A（耶穌的話）
馬大沒有分工 → 情緒爆炸

教會應用

義工不能承擔所有 R
需要分工、需要界線
需要把 A（屬靈優先）放在中心
