③ 填 · 目標與評估（雲端工作台）

準備好了就按下面按鈕開啟工作台。

開啟雲端工作台（Next 專案） 登入頁（若專案有提供）

下面說明正式路線與青年沙盒差在哪裡；需要細節再展開閱讀。

📋 正式路線（長執軌）

給牧者、長執和部門負責人。用來寫正式的年度／三年目標、事工評估和看板。內容會成為長執會、教會議決的參考。

例子：敬拜部在兩年內建立「每月一次禱告會＋每季一次聯合敬拜」，並在每次會後記錄參與人數與回饋。

🧪 青年沙盒（實驗區）

給年輕同工、小組長、創新團隊。可以提出「先試一試」的點子，不用一開始就承諾很多資源。若試驗結果好，再「升級」到正式目標。

例子：先辦兩次「週五晚禱告＋分享」試水溫，再決定是否列入下一年度計畫。

怎麼選？ 若你是青年、小組領袖，可以先從青年沙盒開始；若你是長執或部門負責人，請使用正式路線。兩邊可以並行，只是責任與議程深度不同。
第一次請先做：
1）在電腦安裝 Node 20+　2）到 Supabase 建立專案並貼上金鑰（見 church-planning/docs/小白第一次設定.md）
3）在資料夾 church-planning 執行 npm install 再 npm run dev，依終端機顯示的網址在瀏覽器開啟工作台

若按了打不開：請確認已在 church-planning 成功執行 npm run dev，並使用終端機顯示的網址。
