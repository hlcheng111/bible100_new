規劃模組（CTA-OS）

  • 評估工具（CTV）產生報告時，cta_os_bridge.js 呼叫 syncPlanningAssessmentFromCtaReport，寫入 Smart Ministry 人才評估。
  • CTA-OS 戰情室 已載入 ChurchDataBridge，可檢視規劃風險與行動項。
  • 規劃待辦可出現在教會事工儀表板工作桌「CTA-OS」分類（與新人／關懷／晉升並列）。
  • 入口：評估 OS 總覽、戰情總覽。

與教會 CRM／事工部門

  • 會友屬靈階段、探訪事件、360 時間軸 — 見 會友整合、探訪工作桌。
  • 配對建議經人工確認後寫入志工排班；志工整合 顯示「本崗建議人選」。
  • 研究頁：屬靈階段漏斗（原 analytics 已導向 research）。

選用：上雲 demo（CRM-5）

  • 本機 API：node scripts/church_api_local_server.js；設定 js/cloud_config.js 的 USE_API、REQUIRE_AUTH。
  • 登入：雲端登入（試用 pastor/demo123）。
  • 成熟度 ≥90%：載入 CRM 成熟度種子。
  • AI 牧養草稿：Prompt → 外部 LLM → 人工確認後寫入事件（非站內 API Key）。

與智慧事奉 Smart Ministry 的銜接

堂會完成健康與策略節奏後，第二階「事奉／人力」盤點可與 智慧事奉路線圖（四步：Be known → Discern → Fit → Grow）、 牧者／同工使用指南 併讀。2026-05 起：CTA-OS 評估報告可自動 attachAssessmentToTalent 寫入 Smart Ministry（經 ChurchDataBridge）；配對確認後可晉升為志工排班。個人敏感 raw 仍留本機，不預設上傳 Sheets。詳見 LANDING_UX_PRINCIPLES.md、CRM-5 上雲說明。
