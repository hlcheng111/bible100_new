# 兒少 UI 規格 V1（初稿）

## 設計目標

兒童、青少年 **看見就歡迎、敢點、玩得開心**；家長可同跑；名稱標題後改。

## 色彩

- 背景：奶油黃 `#FFF8E7` / 少年淡紫 `#EEF2FF`
- 主色：珊瑚紅 `#FF6B6B`、薄荷 `#4ECDC4`、陽光黃 `#FFE66D`
- 每關獨立三色組（見 `kids_youth_content.json`）

## 流程

```
歡迎 → 選跑者（兒童/少年）→ Tab：今日 | 地圖 | 同跑隊 | 獎品 | 更多
                              ↓
                         關卡閱讀 → 小遊戲 → 貼紙解鎖
```

## 頁面

| 頁 | 要素 |
|----|------|
| 歡迎 | 吉祥物 🦁、大按鈕、裝飾 emoji、免註冊 |
| 選跑者 | 兩張大卡片 |
| 今日 | 橫幅、今日關卡、同跑隊條、快捷入口 |
| 地圖 | 彩色關卡列表、解鎖順序 |
| 同跑隊 | 頭像、進度條、成員狀態 |
| 獎品 | 貼紙網格 35 格 |
| 更多 | 補給站連結、換跑者、進修預留 |
| 閱讀 | 全幅色塊頭圖、故事、金句、經文、行動 |
| 遊戲 | 三選一 + 過關動畫 |

## 內容量

- 兒童 20 關 + 少年 15 關 = **35 關**（每關含中英故事、遊戲、貼紙）
