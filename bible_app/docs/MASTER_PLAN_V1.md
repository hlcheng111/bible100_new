# 聖經旅程 App — 計劃總說明書 V1.0

**狀態：** 已開工（UI 兒少優先）  
**日期：** 2026-06-11  
**前哨／補給站：** [bible100.lovestoblog.com](https://bible100.lovestoblog.com)

## 當前開工範圍

**第一優先：** 兒童、青少年看見即 **歡迎、敢用、樂用**；每頁彩色、內容充裕。  
**V2 已加：** 入口大廳（5 對象）· 66 卷書目 · 30 日 · 100 金句 · 主題讀經 · 「更多」放成人/慕道/家長  
名稱、標題、正式品牌 **初稿後再改**。

## 產品一句話

開心長跑、你跑我追、跨代同行；App 是每日跑道，Bible100 是補給站。

## V1 UI 交付（本階段）

| 模組 | 說明 |
|------|------|
| 歡迎頁 | 吉祥物、大按鈕、免登入即玩 |
| 選跑者 | 兒童 / 少年 兩種皮膚 |
| 今日 Home | 彩色卡片、今日故事、5 分鐘標籤 |

| 小遊戲 | 讀後互動（拼字、選答） |
| 獎品牆 | 貼紙／徽章收集 |

| 補給站 | 連到 Bible100 網站 |

## 內容

- `packages/core/data/kids_youth_content.json` — 兒童 20 關 + 少年 15 關（可擴）
- 經文對照 `bookId/chapter`；故事為兒少語氣正文

## 技術

Expo Router + Tabs；`@bible-app/core` 內容目錄；AsyncStorage 進度。

## 後續（非本階段）
