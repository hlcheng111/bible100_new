## ⚠️ 您「應留意但未想到」的關鍵問題

### 1. **備份策略（200GB 災難風險）**
- **問題**：R2 雖穩定，但誤刪無法救回
- **解決**：啟用 Cloudflare **R2 版本控制**（免費），或每月自動備份到**Backblaze B2**（極便宜冷儲存）

### 2. **圖片/影片壓縮（流量關鍵）**
- **問題**：200GB 原始檔案，若教師上傳 4MB 照片，讀者手機載入會極慢
- **解決**：使用 **Cloudflare Images**（$1/1000 張）自動壓縮，或讓 Cursor 加上傳前自動壓縮功能

### 3. **版權與內容審核**
- **問題**：多語言教師分權編輯，可能誤傳不當內容或版權圖片
- **解決**：CMS 設定「**Workflow**」：教師提交 → 總編輯（您）審核 → 發佈

### 4. **小語種特殊字型**
- **問題**：柬埔寨文（Khmer）、緬甸文（Myanmar）等在手機上可能顯示為亂碼（方框）
- **解決**：在 Cursor AI 提示詞中加入「載入 Noto Sans Khmer/Myanmar 等 Google Fonts」

### 5. **離線閱讀（網路不穩地區）**
- **問題**：東南亞偏鄉網路不穩
- **解決**：建立 **PWA**（漸進式網頁應用），讓學生下載課程後離線閱讀（Cursor AI 可生成 service-worker.js）

### 6. **CDN 與全球加速**
- **問題**：Lovestoblog 主機在美國，東南亞讀者連線慢
- **解決**：使用 Cloudflare **Cache Everything** 規則，將靜態 HTML 也快取至全球節點（免費）

3. **文化適宜性**：AI 不知柬埔寨教會習慣用「ព្រះ」還是「អរិយគតិ」來稱呼神，只有當地老師知道哪個詞語在當地教會傳統中是合適的。

**即時AI翻譯只應作為**：「老師臨時想查某個字」的辅助工具，而非主要教學內容的依賴。

-- 書卷表
CREATE TABLE books (
    id SERIAL PRIMARY KEY,
    osis_id VARCHAR(10) UNIQUE, -- 'Gen', 'Exod'
    name_zh VARCHAR(50),        -- '创世记'
    name_en VARCHAR(50),        -- 'Genesis'

);

    book_id VARCHAR(10),
    chapter INT,

    text_cuv TEXT,
    text_esv TEXT,
    text_osis TEXT,             -- 原文標記
    UNIQUE(book_id, chapter, verse)
);

-- 釋經書表
CREATE TABLE commentaries (
    id SERIAL PRIMARY KEY,
    book_id VARCHAR(10),
    chapter INT,
    start_verse INT,
    end_verse INT,
    author VARCHAR(100),        -- 'Matthew Henry', 'Bridegway'
    language VARCHAR(10),       -- 'zh', 'en', 'mya'
    content TEXT,
    source_url VARCHAR(255),
    created_at TIMESTAMP
);

-- 索引優化
CREATE INDEX idx_commentary_lookup ON commentaries(book_id, chapter, language);
