# 全站雙語（英譯作 Bridge）政策 — 記錄在案

**版本**：1.0  
**日期**：2025-03-24  
**狀態**：政策草案，待有額度時分階段實作  

---

## 一、定位

- **英文譯文**定位為 **bridge（橋接）**：協助母語非中文、但較常接觸英文的使用者理解介面與核心概念。  
- **現階段不提供**獨立的 **vi / id / th** 等完整語系介面，除非日後配套**字串管理**或明確**分階段**計劃。  
- **英文（EN）模組**：若該模組本身以英文為主體，**不必**再強制疊加中英雙行，避免冗餘。

---

## 二、分階段原則（與字串管理）

1. **優先**：建立**全站雙語樣式規範**＋**至少一個示範頁**（驗證字級、顏色、`lang`、手機換行）。  
2. **第一波雙語範圍**（可規定僅下列先上線）：  
   - **導航**（頂欄、側欄、麵包屑）  
   - **標題**（頁面 `h1`／區塊主標）  
   - **關鍵說明**（每頁首段或「本頁用途」類短文案）  
3. **長文**：採 **「摘要英譯＋全文維持單一語言」**，或 **連結到英文頁／英文段落錨點**；過渡期可採 **Google 翻譯（或站內既有翻譯入口）** 作補救，但須在頁面註明「機譯僅供參考」。  
4. **字串管理**：若模組數與文案量持續成長，應導入 **集中字串表**（JSON／YAML／建置替換）或等效流程，避免每頁 HTML 手寫雙語難以維護。

---

## 三、模組與內容層級（細化）

### 3.1 模組／功能／核心 landing、說明頁

- **目標**：**模組首頁、功能總覽、核心 landing、說明頁** — 在資源允許下，**正文亦應提供全文英譯**（或獨立英文頁與中文頁對等連結），與「僅導航雙語」的過渡規定並存時，以本節為**較高優先**。

### 3.2 聖經研讀結構：OT、NT、T4 及多語 landing

- **OT**（舊約）、**NT**（新約）、**T4**（四寶／平台內約定縮寫）及 **vi / id / lo / bu** 等語言 landing 路徑：  
  - **至少**：**大標題、小標題**（章節層級）附 **英譯**（或並列英文副標）。  
  - **所有關鍵詞**（神學、教會用語、專有名詞）**最好**有英譯或括號英文對照（詞彙表可集中維護，避免同一詞多種譯法）。

### 3.3 與「僅導航、標題、關鍵說明先雙語」的關係

- **不衝突**：先執行「導航／標題／關鍵說明」可快速覆蓋全站；**模組 landing、說明頁全文英譯**列為**同政策內**的**進階／完整目標**，依模組優先度排程。  
- **長文**：仍優先採 **摘要英譯＋全文單語**、**英文頁連結**，或 **機譯補救**（見第二節），直至有全文人工譯。

---

## 四、樣式與無障礙（設計）

- **主文**：中文（或該頁主語言）維持主要字級與字重。  
- **英文副文**：建議較小一級、較淡色階、必要時獨立一行；英文區塊使用 **`<span lang="en">`** 或 **`lang` 屬性**，利於螢幕報讀與字型選擇。  
- **全大寫**：僅限極短標籤，避免長句全大寫。  
- **長度**：英文常較長，導航與按鈕需預留換行與 RWD。

（具體 CSS 類別名可於實作時定於 `church_ministry/css/module_onboarding.css` 或全站 `docs` 所附樣式規範。）

---

## 五、機譯（Google Translate 等）補救

- **用途**：過渡期、或長文尚未全文英譯時。  
- **要求**：頁面須標示 **機譯僅供參考**；神學／教會用語應逐步改為**人工對照**或**詞彙表**。  
- **技術**：與現有 **help/translate.html**、頂欄「工具 ▾」翻譯流程可並存，不強制單一路徑。

---

## 六、實作與維護考量

- **譯名一致性**：牧者／職位／聖經用語（例：pastor / overseer）需統一對照表。  
- **SEO 與結構**：主標題語義清晰，避免同一頁堆疊多個無層級的 `h1`。  
- **法律與隱私**：雙語表單、同意條款須同步更新。  
- **排程**：不必等「全部模組重整完」才開始；先 **樣式＋示範頁**，再依 **核心 landing → 儀表板 → 導航 → 各模組說明頁** 滾動推進。

---

## 七、與其他文檔的關係

- 本政策為 **全站層級**；各模組若有專用計劃（如 `smart_ministry/docs/RENOVATION_PLAN.md`），**雙語範圍**應與本政策對齊或註明例外。
