# 六大核心系統資料來源說明

## 資料架構總覽

| 系統 | 資料來源 | 有 charts？ | 如何有資料 |
|------|----------|-------------|-------------|
| 👥 会友事工 | `memberSystemData` (localStorage) | ✅ 有 | 點「從 people.json 匯入 500 人」或「載入 200+ 筆試用資料」 |
| 🎵 敬拜事工 | `churchMasterDatabase` (localStorage) | ✅ 有 | 同上，匯入後會同步 members、teams、teamMembers |
| 🏠 小组事工 | `churchMasterDatabase.fellowship` | ✅ 有 | 同上 |
| 👔 志工事工 | `churchMasterDatabase.volunteer` | ✅ 有 | 同上 |
| 🎓 教育事工 | `churchMasterDatabase.education` | ✅ 有 | 同上 |
| 💰 财务事工 | `churchMasterDatabase.finance` | ✅ 有 | 同上 |

## 如何讓六大系統都有 500 人資料與 charts

1. **啟動 HTTP 伺服器**：雙擊 `啟動.bat` 或執行 `python -m http.server 8080`（在專案目錄）
2. **開啟**：http://localhost:8080/church_ministry/load_central_member_seed.html
3. **點擊**：「📥 從 people.json 匯入 500 人」
4. **重新整理**：會友事工、敬拜事工、小組事工等頁面

匯入後會同步至：
- `memberSystemData` → 会友事工、人員總覽
- `churchMasterDatabase` → 敬拜、小組、志工、教育、財務

## data/people.json 是什麼？

- **純資料檔**：只有名單（姓名、性別、地區、教會、出席、標籤等）
- **沒有 charts**：charts 由各 HTML 頁面用 Chart.js 依資料繪製
- **用途**：人員總覽、會眾入口統計、匯入至六大系統

## 常見問題

**Q: 人員總覽顯示「尚無人員資料」？**  
A: 確認用 HTTP 伺服器開啟（非 file://），且 `/data/people.json` 可存取。

**Q: 敬拜事工沒有 charts？**  
A: 先到「載入中央試用資料」頁面，點「從 people.json 匯入 500 人」，再重新整理敬拜事工。

**Q: 會友事工有 charts 但敬拜沒有？**  
A: 兩者用不同 localStorage key。匯入 500 人會同時寫入兩邊。
