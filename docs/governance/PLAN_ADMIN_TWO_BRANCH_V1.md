## 為什麼要「雙欄互切」（左＋右一起換）

總站是左右兩個 iframe：`sidebarFrame`｜`contentFrame`。

| 做法 | 結果 |
|------|------|
| **只換右欄** | 左欄仍是「規劃」地圖，右欄卻是「行政」頁 → 看起來像「回則欄錯了／點回去側欄不對」 |
| **雙欄一起換** | 左＝該分支側欄，右＝該分支內容 → 地圖與內容一致 |

跨分支（規劃 ↔ 行政）必須用 `bible100ShellNav` 或 `data-b100-nav="module"`（同時帶 `data-b100-sidebar` + `data-b100-content`）。  
**同分支內**（例如行政裡點會友、財務）→ 只換右欄即可。

## 為什麼「行政」預設右欄用 dashboard，不是會友？

| 頁 | 角色 |
|----|------|
| `dashboard.html` | **行政總覽入口**（戰情／就緒度）→ 適合作分支首頁 |
| 會友主檔 | **日常工具第 1 步**→ 放在行政側欄置頂，由使用者點進 |

避免一進行政就跳進名冊表單，找不到「我在哪一層」。

**模式預設入口**＝**規劃**（`index_plan`），因產品敘事以六步決策河為主；行政由頂欄「行政」或規劃第 6 步進入。
