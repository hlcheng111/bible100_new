# Bible100 產品憲法（PRODUCT CONSTITUTION）

> **版本**：V1 · 2026-07-24  
> **一句話**：萬變不離其宗——教聖經、出教材、小白能用能維護；輔助模組服務「讀好、實踐、建立教會」。  
> **效力**：與 `UNIFIED_NAVIGATION.md`、`bible100-current-governance` 並列；衝突時以**使用者最新指令**與**本憲法初心**為準。

---

## 一、網站平台初心理念（宗）

### 1.1 為何存在

| 層 | 使命 |
|----|------|
| **核心** | 教導聖經；產出教材（聖經 100 步、信徒四寶）；服務四語／六語**小白**，使其可使用、可維護、可發展 |
| **延伸** | 為讀好聖經、能實踐，添加輔助模組（研讀、難題、教會、學校、AI／營運等）——由深研到建立教會 |

### 1.2 體驗志向

| 階段 | 目標 |
|------|------|
| 易用 → 肯用 | 找得到、不迷路、本地／USB 也能開 |
| 好用 → 愛用 | 任務一次做完；現代 AI 當助手（草稿須人審） |
| 淺入深 | 內容古今中外有序；學生可長成老師、小白可長成專家 |

### 1.3 大模組地圖（頂欄1）

| 模組 | 角色（相對初心） |
|------|------------------|
| 教材與培訓 | **核心**：語言教材 |
| 聖經研讀 | 輔助：深讀／釋經 |
| 聖經難題 | 輔助：答疑／備課素材 |
| 教會事工 | 輔助：實踐與教會建造（0＋A–F） |
| 學校管理 | 輔助：學籍／課程體制 |
| AI 輔助 | 輔助：備課／草稿／自動化入口 |
| 營運自動化（若獨立露出） | 輔助：與教會 CRM／會友主鍵銜接，**不另造一套人** |

## 二、四身份平衡（任何大改必過）

| 身份 | 成功標準 | 設計含義 |
|------|----------|----------|
| **小白** | 10 分鐘內知道「在哪個模組、怎麼回家」 | 頂欄2 小標＝**模組正式名**；地圖內左欄穩定 |
| **日常同工** | 少點幾下完成點名／排班／備課 | 允許「工作桌深鏈」，但不得劫持地圖預設 |
| **牧長／長執** | 看得懂區碼與進度 | 每模組編號 SSOT；報告可追 |
| **工程／維護** | 不頭痛醫頭 | 一波一主題；契約測試；跨模明示 |

**四全其美口訣**：地圖穩 · 做事深 · 出國明 · 編號追。

## 三、導覽三層（與技術對齊）

| 層 | 使用者心智 | 技術 |
|----|------------|------|
| **選國** | 頂欄1 大模組 | `modes.json` mode |
| **看地圖** | 頂欄2／長側欄 | 同模組內 `content` only |
| **做事** | 右欄（可再 L4 Tab） | 功能頁／工作桌 |
| **出國** | 換另一大模組 | 必須 `module` 或頂欄1，文案標「換模組／換側欄」 |

**禁止**：在地圖層 silent 換成另一模組側欄（小白會以為還在原模組）。

教會事工 C 區：預設留在 `sidebar_church_layout_v1`；主日學五 Tab 為右欄工作桌。專用紅側欄僅作**明示捷徑**，不作頂欄 C 的預設劫持。

## 四、全站改良波次（防掛一漏萬）

| 波次 | 名稱 | 產出 |
|------|------|------|
| **W0** | 憲法落地 | 本檔＋頂欄小標＝模組名＋導覽例外收斂 |
| **W1** | 地圖 SSOT | 每模組一張編號／成熟度表（教會已有 0–F） |
| **W2** | 殼契約 | Hub／Standalone 進法一致；HTTP 查驗 Hub |
| **W3** | 行為統一 | 地圖內只換右欄；跨模明示 |
| **W4** | 工作桌打磨 | 高頻頁 Tab／報告／亂碼類 |
| **W5** | 愛用劇本 | 小白任務抽樣（備課／點名／排班／查經） |

**原則**：先 W0–W3 複製到各模組，再深做 W4；禁止同時大改三個模組 IA。

## 五、AI 與成長路徑

- AI＝助手草稿，不取代牧者／老師；須引用經文、不確定則明說。  
- 小語種＝暫譯＋人審；保留中文橋接。  
- 產品路徑：學生用教材 → 同工用工具 → 老師用 AI 備課 → 專家維護與擴充。
