## 每位测试者准备

- 浏览器 Chrome/Edge，无痕或 Ctrl+F5  
- 15～25 分钟 uninterrupted  
- 填写 `UX_SCORE_SHEET_{tool_id}.md`（可复制 MASTER 输出格式）

## 单工具流程（15 分钟）

1. Tab ① 读 3 分钟入门 → 点示范报告  
2. Tab ② 填完或看示范 → 提交  
3. Tab ③ 读 report-heart + 报告 → 是否愿意做「一小步」  
4. Tab ④ 扫一眼辅导员手册 → 是否敢带小组  

## 通过线（Charter 对齐）

- A～D 四区均分 **≥3.5** → 可标 Silver UX  
- 任一题 **≤2** → 必须写 PATCH 进 `{tool_id}.md` §5，Gold UX 阻塞  
- E3「只想改一处」→ 优先 P1 队列
