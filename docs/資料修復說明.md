# 資料修復說明

## 已修復項目

### 1. 會眾入口 Church Center 無資料
- **原因**：會眾入口只用 `people.json`（fetch），與 `memberSystemData`（load_central_member_seed 匯入後）不同源
- **修復**：加入 **memberSystemData 備援**。當 people.json 載入失敗或為空時，改顯示 `memberSystemData` 的會友資料
- **操作**：先到「載入中央試用資料」點「從 people.json 匯入 500 人」，再開會眾入口即可看到資料

### 2. 人員總覽（我的參與）無資料
- **同上**：加入 memberSystemData 備援
- **顯示**：若使用備援，會顯示「已從會友系統載入 XXX 筆（備援）」

### 3. 敬拜事工完整系統 無資料／charts 不顯示
- **原因**：頁面使用未定義的 `data` 變數，且缺少 `saveData()`
- **修復**：補上 `const data = db.data.worship`、`saveData()`、`data.songLists`
- **資料來源**：`churchMasterDatabase`。匯入 500 人時會同步 members、teams、teamMembers

### 4. 匯出／報表自選欄位 無跟著變化
- **原因**：自選欄位只影響匯出，表格欄位固定
- **修復**：勾選「匯出時僅包含以下勾選欄位」時，表格欄位會依勾選同步顯示；勾選變更時會即時重繪

## 資料流總覽

```
people.json (檔案)
    ↓ fetch
peopleDB (people_loader.js)
    ↓ 會眾入口、人員總覽（主要）
    ↓ 失敗時
memberSystemData (localStorage) ← 備援

load_central_member_seed「從 people.json 匯入 500 人」
    ↓
memberSystemData + churchMasterDatabase
    ↓
会友事工、敬拜事工、小組、志工、教育、財務
```

## 建議操作順序

1. 雙擊 `啟動.bat` 啟動 HTTP 伺服器
2. 開啟 http://localhost:8080/church_ministry/load_central_member_seed.html
3. 點「📥 從 people.json 匯入 500 人」
4. 重新整理會眾入口、人員總覽、敬拜事工等頁面

## 其他子模組（敬拜管理、講壇事奉、招待等）

這些子模組各自使用不同的 localStorage key（如 `worshipData`、`choir_members` 等），目前尚未與 memberSystemData 串接。後續可逐步：
- 在子模組加入「從會友系統載入」按鈕
- 或建立統一橋接層，讓子模組可選用 memberSystemData 作為人員來源
