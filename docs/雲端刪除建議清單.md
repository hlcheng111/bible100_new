# 雲端 /htdocs 建議刪除清單（騰出空間解決 553 Disk quota exceeded）

在 FileZilla **右側**連到 `/htdocs` 後，依序檢查並刪除下列項目。

---

## 🔴 優先刪除（通常可省最多空間）

| 遠端路徑 | 說明 | 預估可省 |
|----------|------|----------|
| **backups/** | 本機備份，雲端不需要 | 數百 MB～1 GB+ |
| **data/** | 資料庫／JSON，靜態站通常用不到 | 數百 MB～1 GB+ |
| **data/orig/** | 原始資料（gb_parsing 等） | 數百 MB |
| **data/cj/** | 註釋資料 | 數十～數百 MB |
| **data/cd/** | 其他資料 | 數十 MB |
| **data/bibles/** | 聖經資料（若首頁不依賴） | 數十 MB |

---

## 🟠 次優先刪除（若空間仍不足）

| 遠端路徑 | 說明 | 預估可省 |
|----------|------|----------|
| **disciple_dynamics/** 內 PDF | `disciple_d text` 或 `*.pdf` | 數十～數百 MB |
| **languages/** 內非必要語言 | 只保留 1～2 種（如 cn, en），其餘刪除 | 依語言數量，可省數百 MB～1 GB |
| **alternatives/** | 若為舊版或備用，可刪 | 視內容 |

---

## 🟡 視情況刪除（不影響首頁即可）

| 遠端路徑 | 說明 |
|----------|------|
| **visitation/** | 若暫時不用探訪模組 |
| **hymn_management/** | 若暫時不用詩歌管理 |
| **school_management/** | 若暫時不用學校管理 |
| **qna/** 內大檔 | 如 qna_list_auto.htm（約 4.3 MB）若主機有雲端版可改用 |
| **.git/** | 若誤傳了 Git 資料夾，可刪 |

---

## ✅ 建議保留（首頁與核心功能需要）

- **index.html**（你要上傳的）
- **index_backup.html**、**404.html**
- **languages/index_cn.html**、**landing_new_cn.html**、**landP_cn.html**（至少一種語言的入口）
- **ai_tools/**（若要用 AI 工具）
- **js/**、**css/**、**config/**
- **nav_hub/**、**bible_study/**、**church_ministry/**（若首頁有連結）

---

## 操作步驟（FileZilla）

1. 右側連到 `/htdocs`
2. 找到 **backups** → 右鍵 → **刪除**
3. 找到 **data** → 右鍵 → **刪除**
4. 若仍有 **553**，再刪 **disciple_dynamics** 內大 PDF 或 **languages** 內多餘語言
5. 刪完後，左側拖 **index.html** 到右側上傳
