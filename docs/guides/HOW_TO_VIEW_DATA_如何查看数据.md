# 📖 如何查看浏览器中的真实数据

## 🔍 **方法1：使用浏览器开发者工具查看数据**

### **详细步骤（带截图说明）**

#### **步骤1：打开数据库页面**
```
1. 双击打开文件：
   C:\Users\hlche\.cursor\bible100_new\working_database_system.html

2. 页面会在浏览器中打开
```

---

#### **步骤2：打开开发者工具**

**有3种方法：**

**方法A：按键盘快捷键**
```
按 F12 键
```

**方法B：右键菜单**
```
1. 在页面任意位置右键点击
2. 选择"检查"或"Inspect"或"检查元素"
```

**方法C：浏览器菜单**
```
Chrome浏览器：
菜单 → 更多工具 → 开发者工具

Edge浏览器：
菜单 → 更多工具 → 开发者工具

Firefox浏览器：
菜单 → Web开发者 → 开发者工具
```

---

#### **步骤3：找到 Application 标签**

**开发者工具打开后，您会看到顶部有多个标签：**

```
┌─────────────────────────────────────────────────────────┐
│ Elements  Console  Sources  Network  【Application】  ...│
│                                        ↑                 │
│                                    点击这个标签           │
└─────────────────────────────────────────────────────────┘
```

**如果找不到 Application 标签：**
- Chrome/Edge: 点击 `>>` 符号，在下拉菜单中找到 "Application"
- Firefox: 这个标签叫 "存储" 或 "Storage"

---

#### **步骤4：找到 Local Storage**

**在 Application 标签的左侧，您会看到一个树形列表：**

```
Application
├── Application (应用)
├── Storage (存储)
│   ├── 【Local Storage】← 点击展开这个
│   │   └── file://      ← 再点击这个
│   ├── Session Storage
│   ├── IndexedDB
│   └── Cookies
├── Cache
└── Background Services
```

**操作：**
1. 找到 "Local Storage" （本地存储）
2. 点击左侧的小三角 ▶ 展开
3. 看到 "file://"
4. 点击 "file://"

---

#### **步骤5：查看真实数据**

**点击 file:// 后，右侧会显示一个表格：**

```
┌──────────────────────┬────────────────────────────────┐
│ Key (键)             │ Value (值)                     │
├──────────────────────┼────────────────────────────────┤
│ bible100_database    │ {"members":{"schema":{...},... │
│                      │                                │
│ ← 点击这一行          │ ← 这里就是真实的数据！           │
└──────────────────────┴────────────────────────────────┘
```

**您会看到：**
- **Key (键)**: `bible100_database`
- **Value (值)**: 一大串 JSON 数据，包含所有表和记录

**点击 Value 那一列，可以查看完整的数据内容！**

## 📂 **支持的文件格式**

### **1. JSON 格式** ✅

**文件扩展名：** `.json`

**如何打开：**
```
1. 点击"文件(F)" → "打开数据库"
2. 选择 .json 文件
3. 点击"打开"
4. 确认导入
```

**用途：**
- 导入之前导出的数据库备份
- 导入手动编辑的JSON数据
- 在不同电脑之间传输数据

**优点：**
- 文本格式，易于查看和编辑
- 支持中文
- 可以手动修改数据

---

### **2. SQLite 格式** ✅ **新增支持！**

**文件扩展名：** `.db` `.sqlite` `.sqlite3`

**如何打开：**
```
1. 点击"文件(F)" → "打开数据库"
2. 文件类型选择：所有支持的格式
3. 选择 .db 文件（如：圣经综合解读.db）
4. 点击"打开"
5. 确认导入
```

**支持的文件：**
- `data/commentaries/圣经综合解读.db`
- `data/bibles/和合本.db`
- 任何标准的SQLite3数据库文件

**功能：**
- 自动读取所有表
- 自动识别字段类型
- 导入所有数据
- 支持中文内容

**优点：**
- 可以直接打开现有的.db文件
- 支持复杂的数据结构
- 数据完整性高

---

### **3. CSV 格式** ✅

**文件扩展名：** `.csv`

**如何导出：**
```
1. 选择要导出的数据表
2. 点击工具栏"导出Excel"按钮
3. 保存CSV文件
4. 可以用Excel打开
```

**用途：**
- 导出单个数据表
- 在Excel中编辑数据
- 与其他系统交换数据

**优点：**
- Excel可以直接打开
- 支持中文（UTF-8 BOM）
- 简单易用

## ❌ **常见问题和解决方法**

### **问题1：找不到 Application 标签**

**解决方法：**

**Chrome/Edge浏览器：**
```
1. 开发者工具顶部标签可能被隐藏
2. 找到 ">>" 符号（在标签栏最右边）
3. 点击它，在下拉菜单中选择 "Application"
```

**Firefox浏览器：**
```
Application 标签叫 "存储" 或 "Storage"
直接点击 "存储" 即可
```

---

### **问题2：Local Storage 是空的**

**可能原因：**
- 页面还没有初始化数据
- 浏览器隐私模式（无痕模式）

**解决方法：**
```
1. 刷新页面（F5）
2. 等待页面完全加载
3. 在页面上点击"生成示例数据"按钮
4. 再次查看 Local Storage
5. 确保不在隐私/无痕模式下浏览
```

---

### **问题3：打开 .db 文件失败**

**可能原因：**
- 文件损坏
- 不是标准的SQLite格式
- 网络连接问题（需要下载SQL.js库）

**解决方法：**
```
1. 确保文件是有效的 .db 文件
2. 确保网络连接正常（需要加载SQL.js库）
3. 检查浏览器控制台（F12 → Console）查看错误信息
4. 如果是网络问题，可以先使用示例数据测试
```

---

### **问题4：导入后看不到数据**

**解决方法：**
```
1. 检查左侧侧边栏，确认表已经导入
2. 点击表名，查看右侧是否显示数据
3. 如果表是空的，说明原始.db文件中该表就是空的
4. 检查浏览器控制台是否有错误信息
```
