🐍 方法1: Python脚本（推荐）

  • 安装 Python

    如果还没有安装Python，访问: https://www.python.org/downloads/

    下载并安装最新版本 (3.8+)

  • 安装 Pillow 库

    打开命令行/终端，运行:

    pip install Pillow
  • 运行优化脚本

    在项目根目录运行:

    python tools/optimize_cj_images.py

    脚本会自动:

    • 扫描 data/cj/ 文件夹
    • 显示找到的图片数量和大小
    • 要求确认后开始优化
    • 显示实时进度和节省空间
  • 测试结果

    优化完成后，请测试图片显示是否正常

💡 高级用法:

如果想使用PowerShell脚本（提供更多选项），运行:

powershell -ExecutionPolicy Bypass -File tools/optimize_cj_images.ps1

🌐 方法2: 在线工具（最简单）

推荐工具:

📦 TinyPNG 🎨 Squoosh (Google) 🔧 Compressor.io

  • 打开图片文件夹
    explorer data\cj
  • 选择要优化的图片

    建议每次选择一个子文件夹的图片（避免一次处理太多）

  • 上传到在线工具

    访问 TinyPNG，拖拽图片上传

    每次最多20张图片

  • 下载优化后的图片

    点击"Download all"下载所有优化后的图片

  • 替换原文件

    将下载的优化图片替换原文件夹中的图片

⚠️ 注意:
  • 在线工具适合处理少量图片
  • 如果有大量图片，建议使用Python脚本或桌面软件
  • 保持良好的文件夹组织，避免混淆

💻 方法3: 桌面软件（专业）

推荐软件:

软件名称 平台 特点 下载链接
XnConvert Windows/Mac/Linux 免费，功能强大，支持批量 下载
FileOptimizer Windows 免费，无损压缩 下载
ImageOptim Mac 免费，简单易用 下载
Caesium Windows/Mac/Linux 开源，批量处理 下载

使用步骤 (以XnConvert为例):

  • 下载并安装 XnConvert

    访问 官网 下载最新版本

  • 添加图片文件

    在"Input"标签页，点击"Add files"或"Add folder"

    选择 data/cj/ 文件夹

  • 设置压缩参数

    在"Actions"标签页，添加"Image" → "Quality"

    设置质量为 85%

  • 配置输出

    在"Output"标签页:

    • Format: JPEG
    • 勾选"Replace original files"（替换原文件）
  • 开始转换

    点击"Convert"按钮开始批量优化
