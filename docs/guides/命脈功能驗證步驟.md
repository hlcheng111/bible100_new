# 命脈功能手動驗證步驟

依 .cursorrules「命脈功能」：綜合解讀釋經書為網站成功標誌。請用瀏覽器依下列步驟確認。

## 前置

- 用本機或區網可開啟網站（例如 `http://127.0.0.1:8765/` 或 `file:///` 開啟專案根目錄）。
- 若用 `file:///`，部分功能可能因 CORS 無法載入資料庫，建議用簡易 HTTP 伺服器（如 `python -m http.server 8765` 在專案根目錄執行）。

## 步驟一：聖經研讀首頁

1. 開啟 **聖經研讀首頁**：  
   - 若用本機伺服器：`http://127.0.0.1:8765/bible_study/index.html`  
   - 或從專案導航進入 `bible100_new/bible_study/index.html`。
2. 確認頁面標題為「聖經研讀中心」、上方有導覽按鈕（如 綜合解讀、串珠、詞典等）。
3. 確認左側或主區有書卷/工具選單，可點選不報錯。

## 步驟二：綜合解讀釋經書

1. 在研讀首頁點 **「⭐ 綜合解讀」** 按鈕，或直接開啟：  
   `bible_study/comprehensive_exegesis_reader.html`
2. 確認頁面標題為「綜合解讀釋經書」、有書卷與章節選擇器。
3. 選一本書（例如「創世記」或「馬太福音」）、再選章（例如第 1 章）。
4. 確認右側或下方有 **釋經內容** 出現（有經文或註釋文字），不是整頁空白或一直轉圈。
5. 切換不同章或不同書，確認內容會更新。

## 通過標準

- 研讀首頁可開啟、導覽可見。
- 綜合解讀頁可開啟、可選書選章、有釋經內容顯示且可翻頁。

若任一步驟失敗（空白、錯誤訊息、無法選書章），請把「哪一頁、哪一步、畫面狀況」告訴 AI 協助排查。
