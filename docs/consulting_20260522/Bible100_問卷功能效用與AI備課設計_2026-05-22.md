# Bible100 問卷功能效用與 AI 備課設計

日期：2026-05-22

## 1. 本輪方向確認

目前先服務中文老師與中文課件。小語種版本建議先用 AI 翻譯作「臨時使用版」，但不可直接視為正式教材；正式版仍需要懂該語言的老師或同工校對。

網站定位為兩用：

- 本機/USB/離線：適合山區、網絡不穩、老師電腦能力有限的場景。
- 線上試用：https://bible100.lovestoblog.com

AI 優先順序：

1. 備課。
2. 查經問答。
3. 教材翻譯與校對。
4. 之後才進入探訪跟進、行政整理、自動化任務。

最大風險不是沒有功能，而是老師不懂用。所以後續開發要以「老師任務」為中心，不以「技術模組」為中心。

## 3. 問卷與測驗功能盤點

目前看到的問卷/測驗/評估類型主要有五類。

| 類型 | 代表檔案 | 目前效用 | 建議 |
|---|---|---|---|
| 學習測驗 | `ai_tools/pages/ai_quiz_generator.html`、各語言 `learning_assessment/quiz_system.html` | 幫老師產生或管理課後測驗 | 應接入備課流程，讓「一課」自動產生 5 題理解題、2 題應用題、1 題反思題 |
| 同儕/學習評估 | `languages/*/learning_assessment/peer_assessment.html` | 可作學生互評或小組回饋 | 先簡化為老師可列印/複製的表單，不急著複雜計分 |
| 教會健康問卷 | `church_planning/planning/survey.html`、`pastoral-spiritual-survey-pro.html` | 供教會健康、會眾/領袖調查使用 | 與聖經課件分開，不要讓初學老師一開始看到太多教會診斷工具 |
| 屬靈恩賜/事奉配搭 | `smart_ministry/spiritual_gifts.html`、`talent_main_survey.html`、`talent_ministry_matching.html` | 幫教會認識恩賜、才幹、事奉配搭 | 需要清楚標示「參考性」，避免老師或領袖把結果當成屬靈定案 |
| 規劃/行動工具 | SWOT、SMART、PDCA、80/20 類頁面 | 幫領袖做事工規劃 | 適合第二階段整合，不宜放在普通老師第一屏 |

## 4. 問卷功能效用總評

### 對中文聖經老師最有用

1. 課後測驗：檢查學生是否明白經文。
2. 反思回應：幫學生把經文連到生命。
3. 老師備課檢查表：確認課程有經文、背景、主旨、活動、應用、禱告。
4. AI 回答審核表：幫老師判斷 AI 是否亂引經文、是否偏離聖經。

### 對教會領袖最有用

1. 教會健康問卷。
2. 牧者/領袖健康問卷。
3. 恩賜與事奉配搭。
4. SWOT、SMART、PDCA、80/20 事工工具。

### 對小語種臨時使用最有用

1. 簡短課件翻譯。
2. 問題與答案翻譯。
3. 老師操作指引翻譯。
4. 不建議先翻譯大量複雜管理頁，因為維護成本高。

## 5. 問卷與測驗的改良原則

1. 每份問卷只解決一個目的：學習、靈命、恩賜、教會健康、回饋不可混在一起。
2. 每頁先寫清楚「這份問卷不是考試/不是定案/不是屬靈判決」。
3. 問卷結果要給老師「下一步行動」，不只是分數。
4. AI 可以幫忙解讀，但必須有老師審核。
5. 小語種版本先用中英對照欄，避免翻譯錯了老師無法回查。

## 6. AI 備課助手第一版設計

第一版不要急著接真 API。建議先做一個「Prompt 生成器 + 備課表單」，讓老師填資料後，一鍵複製 prompt 到 Kimi、ChatGPT、Claude、Gemini 等平台。

### 6.1 老師填寫欄位

- 經文：例如約翰福音 3:16。
- 課程對象：兒童、青少年、成人、小組、初信者、同工訓練。
- 課程時間：30/45/60/90 分鐘。
- 語言：中文為主，可產生英文/越南文/印尼文/柬埔寨文/老撾文草稿。
- 教學目標：認識、理解、應用、背誦、討論、禱告。
- 場景：主日學、小組查經、門訓、營會、探訪前預備。
- 難度：入門、一般、進深。

### 6.2 生成內容

AI 備課助手應產生：

1. 本課主旨一句話。
2. 經文背景。
3. 經文分段。
4. 老師講解大綱。
5. 互動活動。
6. 討論問題。
7. 課後測驗。
8. 生命應用。
9. 禱告方向。
10. 老師審核清單。

### 6.3 安全限制

Prompt 必須要求 AI：

- 不編造經文。
- 不宣稱自己有屬靈權威。
- 不取代牧者、老師、教會傳統與群體分辨。
- 不把有爭議教義說成唯一答案。
- 對不確定內容要明說「需老師查證」。

### 6.4 推薦第一個技術落點

建議新建或改良：

- `ai_tools/tools/bible_prompt_generator.html`

把它做成「中文老師備課 Prompt 生成器」。好處：

- 不破壞現有 `index_v5`。
- 可在線上和本機使用。
- 不需要 API key。
- 老師容易明白：填表 → 複製 → 貼到 AI → 回來修改。

## 7. 下一步技術工作建議

第一優先：

1. 建立 `AI 備課 Prompt 生成器`。
2. 在 `ai_tools/sidebar_lab.html` 或 AI 工具入口加入清楚入口。
3. 為它寫小白使用說明。
4. 先只支援中文備課。
5. 再加入「翻譯成小語種草稿」按鈕。

第二優先：

1. 把課後測驗生成器與備課助手串起來。
2. 建立 AI 回答審核表。
3. 建立中文老師用的標準課件模板。

第三優先：

1. 把中文課件轉成中英對照。
2. 用 AI 翻譯成小語種。
3. 建立人工校對狀態：未校對、初校、已確認。
