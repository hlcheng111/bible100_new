## 二、會眾入口 Church Center

### 2.1 人員總覽（500 人）

- **資料已存在**：people.json → load_central_member_seed → memberSystemData + churchMasterDatabase
- **如何放**：會眾入口已接 peopleDB、memberSystemData、churchMasterDatabase 備援，header 顯示「會員 X 人 · 男 Y 女 Z · 活躍 N」
- **人員總覽卡片**：點擊進入 people_list.html，該頁也接 memberSystemData 備援
- **建議**：維持現狀；若 people_list 仍空，確認 people.json 路徑與 HTTP 伺服器

### 2.2 教會事工儀表板

- **可從既有數字彙總**：
  - 會友分佈：memberSystemData.members（總數、男女、活躍）
  - 小組數：memberSystemData.groups 或 churchMasterDatabase.fellowship.groups
  - 志工／敬拜團隊：churchMasterDatabase.volunteer、churchMasterDatabase.worship
  - 財務：churchMasterDatabase.finance 或 financialData
  - 活動／探訪：visitationData、activities
- **現況**：dashboard 讀 volunteerSystemData、financeSystemData，但 500 人匯入寫入的是 churchMasterDatabase
- **建議**：儀表板加 churchMasterDatabase 備援，優先顯示真實數字

### 2.3 我的參與（非管理人員入口）

- **現狀**：連結到 people_list.html，描述為「個人資料、OT100/NT100/T4 進度」
- **對標構想**：
  - **奉獻**：線上奉獻入口（可連 financial-management 的「新增收入」或獨立奉獻頁）
  - **課程**：報名教育事工課程（school_management、churchMasterDatabase.education）
  - **活動報名**：小組活動、團契報名（activity-management、fellowship）
- **與 School Mgmt、AI Ministry 的關聯**：
  - School Mgmt：學生＝會友，課程報名可對應 memberId
  - AI Ministry：恩賜配對、事奉建議，可從「我的參與」進入
- **建議**：將「我的參與」改為**會眾功能入口**，包含：
  1. 個人資料與讀經進度（現有 people_list）
  2. 奉獻（連結奉獻頁或財務模組的會眾入口）
  3. 課程報名（連結教育／培訓）
  4. 活動報名（連結團契活動）

## 三、策略建議：精簡優先

### 3.1 短期（立即可做）✅ 已完成

1. **儀表板接 churchMasterDatabase**：✅ 已接
2. **會眾入口「我的參與」**：✅ 文案已更新，規劃奉獻／課程／活動
3. **重複模組**：✅ 跨文化、新媒體、靈命成長追蹤只保留一個入口；-ministry、-tracking 頁面導向主頁

### 3.2 中期（需設計）

1. **奉獻入口**：建立會眾用的奉獻頁（簡化版，只填金額、類別、奉獻者 ID）
2. **活動報名**：activity-management 的報名與 memberId 對接
3. **課程報名**：education 與 school_management 的學生／memberId 對接

### 3.3 長期（架構）

1. **統一資料鍵**：cross_cultural / crossCulturalData 等重複 key 逐步收斂
2. **會眾身份**：若有登入，可過濾「我的」奉獻、報名、進度
3. **AI 整合**：AI 助手可讀取會友、事工資料，提供個人化建議

## 四、資料流總覽（500 人匯入後）

```
people.json (500人)
    ↓ load_central_member_seed
    ├→ memberSystemData (會友、小組、事工、培訓、出席、奉獻)
    └→ churchMasterDatabase
        ├→ members
        ├→ worship (teams, teamMembers, services...)
        ├→ fellowship (groups, groupMembers...)
        ├→ volunteer (positions, volunteers...)
        ├→ education (classes, students...)
        └→ finance (incomes, expenses...)
```

**各模組應讀取的 key**：
- 會眾入口、人員總覽、會眾統計：memberSystemData 或 churchMasterDatabase.members
- 敬拜、小組、志工、教育、財務：churchMasterDatabase 對應區塊
- 財務管理（行政管理）：financialData（獨立，可考慮日後同步到 churchMasterDatabase.finance）

## 六、功能說明與使用解說（2025-03 更新）

各功能頁頂部已加入「📋 功能與使用說明」或「📋 功能說明／計畫願景」可摺疊區塊，包含：
- **此頁是為誰而設？** 目標使用者
- **有什麼功能？** 主要功能與資料來源
- **如何入手？** 操作步驟

**範版**：`activities-overview.html`（事工與專案）— 點擊事工卡片進入完整系統，在「目標·進度·成果」分頁維護年度目標與成果。

**已加說明頁**：儀表板、事工與專案、教育／敬拜／小組／宣教完整系統、會友／財務事工、社群與捐款人、會眾統計、願景／路線圖／事工總覽／AI 決策、跨文化／新媒體。

**報表**：會眾統計分析頁「匯出報表」已實作 CSV 下載（統計項目、數值）。

**中央 database 欄位**：目前 memberSystemData、churchMasterDatabase、financeSystemData 已足夠。若需更細統計（如小組參與、事工參與），可於 memberSystemData.members 加 ministryAssignments、groupIds 等欄位。
