# Foundation 0 · 平台薄憲章

**對齊**：`docs/governance/PRODUCT_CONSTITUTION_V1.md`（宗與四身份）  
**本檔角色**：增量索引 + 重檢鐵律；細節以既有治理為準。

## 1. 使命（一句）

幫助小白與老師：**教聖經、出教材、讀完能懂、實踐與建立教會**；AI 只出草稿、人審才正式。

## 2. 架構鐵律

1. **平台殼 + 可獨立模組**（Hub／Standalone 兩級）。  
2. **禁止殼中殼**；外層 iframe 固定 `sidebarFrame` / `contentFrame`。  
3. **地圖內只換右欄**；換大模組必須明示（頂欄或 `data-b100-nav="module"`）。  
4. **成品驗收以 `file://…/index.html` 為準**；HTTP／雲端不一致則修到一致。

## 3. 內容原則

- 經文、譯本、書卷、章節必須可追溯、可核對。  
- 教材／導師內容／Q&A／AI 草稿必須分開標示。  
- **未人審不得標「正式教學／神學結論／牧養指引」**。  
- 外站只連結或按授權；不假設可複製嵌入重發。  
- 多語正式內容須有審核狀態；機翻僅草稿。

## 4. 使用者原則

- 小白優先：每頁回答「我現在可做什麼？」。  
- 不以連續天數／積分代表屬靈成熟。  
- 斷更、未完成、看不懂，都要有可回來的路（**落後可續**）。  
- 私人資料預設私人。

## 5. AI 原則

- AI 不是權威、牧者、輔導或最終決策者。  
- 先經文、先人寫觀察，再開 AI。  
- 不外送個資／兒少／危機內容。  
- 輸出一律「草稿／待核對」；不可自動發布。  
- 現階段不依賴站內 API key；採外部平台複製貼上兼容。

## 6. 技術原則

- 每模組資料邊界清楚；禁止任意讀寫他模 localStorage。  
- 共用「標準契約」，不是共用一團未命名資料。  
- 跨模用標準 URL 參數，不依賴上一頁隱式狀態。  
- **讀者頁禁止技術健康／同步佇列雜訊**（進診斷／管理頁）。

## 7. 風險分級（R0–R4）

| 級 | 例子 | 純本機 | 外部 AI | 必要控制 |
|----|------|--------|---------|----------|
| R0 | 公開導航、公開經文索引 | 可 | 限公開資料 | 連結與內容核對 |
| R1 | 私人進度、私人 OIA | 可 | 去個資後謹慎 | 儲存提示、匯出 |
| R2 | 教材／Q&A 草稿 | 可 | 人審後 | lifecycle 狀態 |
| R3 | 會友／兒少／牧養筆記 | 預設本機 | **禁止** | 權限、最小資料、審計 |
| R4 | 危機／醫療／法律敏感 | 本機或不上站 | **禁止** | 轉介真人制度 |

## 8. 技能包（改法不同）

| 包 | 模組例 | 優先改什麼 |
|----|--------|------------|
| A 經文教學 | 研讀、跑道、教材 | 經文契約、閱讀閉環、OIA |
| B 問答探索 | Q&A、搜尋 | 經文明說 vs 解釋、轉介 |
| C 敏感協作 | 教會、學校 | 權限／最小資料／審計（先設計） |
| D AI 創作 | AI Lab | 任務邊界、人審、禁個資 |

## 9. 禁止（重檢期）

- 同時大改多模組 IA。  
- 盤點期就全站 rename localStorage。  
- 為教會／學校先堆 R3 功能。  
- 發明平行憲法文件與舊 `docs/governance/*` 雙真相。
