# Bible100 獨立測試計劃

## 測試目標
驗證 bible_app 在小白環境下的可用性，測試多語言 UI 切換、離線功能，驗證獨立運行能力。

## 測試環境
- **小白環境**: Windows PC（無開發工具）
- **啟動方式**: 雙擊 `.bat` 檔案
- **測試條件**: 
  - 有網絡連接
  - 無網絡連接（測試離線）

## 測試用例

### TC-01: 啟動測試
- **步驟**: 雙擊 `打開聖經跑道.bat`
- **預期**: 瀏覽器打開 shell/index.html，無錯誤
- **失敗**: 記錄錯誤信息

### TC-02: 語言切換測試
- **步驟**: 點擊語言按鈕（中/EN/VI/ID）
- **預期**: UI 文案切換到對應語言
- **失敗**: 記錄哪些文案未切換

### TC-03: 賽道切換測試
- **步驟**: 點擊賽道按鈕（六十六卷/三十日/100金句/主題讀經）
- **預期**: contentFrame 載入對應頁面
- **失敗**: 記錄哪個賽道失敗

### TC-04: 字體大小測試
- **步驟**: 點擊字體按鈕（小/中/大）
- **預期**: 字體大小正確改變
- **失敗**: 記錄字體未改變

### TC-05: 離線測試
- **步驟**: 斷開網絡，打開 bible_app
- **預期**: 基本功能可用（語言切換、賽道切換）
- **失敗**: 記錄哪些功能需要網絡

### TC-06: 小白引導測試（P0 後）
- **步驟**: 首次打開 bible_app
- **預期**: 顯示 3 步引導
- **失敗**: 記錄引導未顯示或流程錯誤
