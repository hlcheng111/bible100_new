學校管理系統 ER 圖（簡化版 6 表）

學生、家長、課程、報名、選課、成績、繳費

students 學員

  • id (PK)
  • name
  • parentId → parents
  • memberId
  • studentNumber
  • grade, class

parents 家長

  • id (PK)
  • name
  • phone, email

courses 課程

  • id (PK)
  • name, code
  • teacherId
  • syllabus
  • capacity

applications 報名

  • id (PK)
  • studentId → students
  • courseId → courses
  • status
  • appliedAt

enrollments 選課

  • id (PK)
  • studentId → students
  • courseId → courses
  • semester
  • status

grades 成績

  • id (PK)
  • studentId → students
  • courseId → courses
  • score
  • examDate

payments 繳費

  • id (PK)
  • studentId → students
  • amount
  • status
  • paymentDate

PK=主鍵 · FK=外鍵
