📖 功能與使用說明

學校管理系統各模組用途、典型情境、下一步行動

如何啟動？ 不一定要用 .bat。方式一：雙擊 start_http_bible100.bat（自動開瀏覽器）。方式二：在 bible100_new 資料夾執行 python -m http.server 8080，再手動開啟 http://127.0.0.1:8080/

參考：Planning Center Calendar · Registrations · Giving · Check-Ins

📊 儀表板 Dashboard

誰會用到？
主日學負責人、教育事工同工、培訓課程管理者
典型情境
每週一開會前，一眼看見學員數、教師數、課程數、成績完成率、繳費概況
下一步
點快速操作進入學生、課程、財務；首次使用請先「載入示範資料」

👨‍🎓 學生管理 Student Management

誰會用到？
註冊組、班導、行政同工
典型情境
新生報到後新增學生、查詢學生選課、匯出學生名單、批量匯入 CSV
下一步
學生資料 → 新增／搜尋／匯出；學生選課管理 → 連結學生與課程

📚 課程管理 Course Management

誰會用到？
教務、課程規劃、排課同工
典型情境
學期初開設課程、排定教師與時段、查看選課人數、課程評估
下一步
課程列表 → 新增／編輯；課程排程 → 安排上課時間；教師授課管理 → 指派教師

👨‍🏫 教師管理 Teacher Management

誰會用到？
人事、教務、排班同工
典型情境
查看教師授課負擔、教學統計、聯絡教師、連結教會志工（volunteerId）
下一步
教師資料 → 列表與統計；教師授課管理 → 指派課程

🏫 班級管理 Class Management

誰會用到？
班導、教務、分班同工
典型情境
學期初分班、設定班級容量、科目安排、學生分班管理
下一步
班級資料 → 班級列表；科目管理 → 科目設定；學生分班管理 → 將學生分入班級

💰 財務管理 Financial（參考 Planning Center Giving）

誰會用到？
財務同工、會計、出納
典型情境
學費收取與追蹤、收支記錄、財務報表、奉獻／學費分類統計
下一步
學費管理 → 學生繳費狀態；收支管理 → 收入／支出登錄；財務報表 → 匯出 CSV

💬 溝通管理 Communication

誰會用到？
行政、班導、家長聯絡人
典型情境
發送家長通知、公告欄張貼、內部訊息傳遞
下一步
家長溝通 → 發送訊息；公告欄 → 張貼公告；內部訊息 → 同工間聯絡

🎉 活動管理 Activities（參考 Planning Center Calendar + Registrations）

誰會用到？
活動策劃、營會負責人、社團輔導
典型情境
營會／退修會排程、活動報名、競賽管理、社團名單、設施預約
下一步
活動管理 → 新增活動、報名名單；競賽管理 → 賽事設定；社團管理 → 社團與成員

⚙️ 系統設置 System Settings

誰會用到？
系統管理員、IT 同工
典型情境
管理員帳號、資料庫備份／匯出、系統資訊、離線工具、多校區／語言設定
下一步
管理員 → 權限；資料庫 → 匯出 JSON；離線工具 → HTML 編輯器、匯入匯出

🔄 載入示範資料

誰會用到？
首次使用、測試、展示
典型情境
第一次開啟系統時，點「載入示範資料」可自動建立 200 學生、25 教師、30 課程、20 班級、選課、成績、繳費等
下一步
載入後返回儀表板即可看到真實數字
