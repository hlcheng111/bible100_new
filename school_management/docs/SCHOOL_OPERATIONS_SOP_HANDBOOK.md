# 學校管理 · 營運 SOP 手冊（SOP-1～9）

**版本**：2026-07-26（W0–W8 完工版）  
**適用模組**：`school_management/`  
**入口**：總站 `index_v5.html` → 頂欄「學校管理」→ 左側欄／儀表板  
**資料主檔**：`schoolMasterDatabase`（本機 localStorage）  
**三大原則**：人 → `memberSystemData` · 事 → 主日學工作桌／學校學籍 · 錢 → `financeSystemData`

> **紅線**：單機模式同一時間只有一台是主檔；AI／通知／CRM 預填皆 **不會自動發送或寫入 SSOT**，須人工確認。

## SOP-1 · 首次啟用（校長／管理員，一次性）

**目的**：正式開學前把環境、學年、備份準備好。

| 步驟 | 操作 | 路徑 |
|------|------|------|
| 1 | 開啟學校管理，看頂部**信任橫幅** | `school_management/index.html` |
| 2 | 若顯示「示範／種子資料」且要正式用 → 清種子或重來 | 系統 → **🔄 載入示範**（僅示範時用）／**💾 資料備份** → 清種子 |
| 3 | 設定學校名稱、語言 | 系統 → **離線工具** |
| 4 | 填「關於本校」公告 | 儀表板 → **✏️ 編輯此區**（`dashboard_intro`） |
| 5 | 建**學年學期**（W3） | 系統 → **📅 學年學期** |
| 6 | 建班級、科目、課程 | 班級 Tab、課程 Tab |
| 7 | **全庫匯出**存兩份 | 系統 → **💾 資料備份** → 匯出 JSON |

**完成標準**：新機 0 筆或僅真實資料；學期已選；備份檔已存到本機＋隨身碟／私人雲端。

---

## SOP-2 · 學生註冊接龍（教務）

**目的**：從招生到取錄、入班、首期學費銜接。

| 步驟 | 操作 | 路徑 |
|------|------|------|
| 1 | 家庭索取簡章 | **📋 招生簡章**（可列印） |
| 1b | （選）生成招生 AI 文案 Prompt | 招生簡章 → **W8 招生 AI Prompt** 或 **✨ AI Prompt W8** |
| 2 | 家庭填報名 | **學員入口** → 新生註冊（狀態 `pending`）或教務代填 |
| 3 | 審核 pending：會友家庭 → **從會友選人** 綁 `memberId` | 學生 → 新增／列表 |
| 4 | **取錄** → 狀態 `active` | 學生列表 → pending 一鍵取錄 |
| 5 | **選科入班** | **統一管理**（三欄） |
| 6 | 通知出納登記首期學費 | → SOP-3 |

**完成標準**：儀表板「已連結會友比例」正確；pending 清零；學生已入班。

---

## SOP-3 · 收費及入帳（出納）

**目的**：校內學費記錄清楚，月末可與教會財政對帳。

| 步驟 | 操作 | 路徑 |
|------|------|------|
| 1 | 建應收（學生／學期／金額） | 財務 → **學費管理** |
| 2 | 收款後 **標記已繳**＋收據編號 | 同上 → 標記已繳 |
| 3 | **列印收據** | 學費頁／學員入口「我的繳費」 |
| 4 | 家長通知（選） | W7：**溝通 → 家長通知草稿** → 繳費提醒 → 複製（不會自動發送） |
| 5 | **每月最後主日**：匯出至教會財政 | 學費 → 匯出 JSON／CSV → 交 F 區同工匯入 `financeSystemData` |

**完成標準**：已繳有收據號；`exportedToChurchFinanceAt` 標記避免重複匯出；F 區可對帳。

## SOP-4 · 開課排班（教務＋老師）

**目的**：學期課程排定、無衝堂、老師可備課。

| 步驟 | 操作 | 路徑 |
|------|------|------|
| 1 | 新增課程（學期、教師、教室） | 課程 → 列表 |
| 2 | 教室來自物業（W5） | 物業 → 場地；排課下拉接 `property.rooms` |
| 3 | **週課表**檢查衝堂 | 課程 → **📅 週課表**（紅色＝衝堂） |
| 4 | 老師備課 | 課程列表 → **C 區備課工具**（`edu_teaching.html`） |
| 5 | AI 教案（選，須人審） | 外部 AI 或 C 區既有草稿模式 |

**完成標準**：老師能看自己的週課表；衝堂已調整；租約快到期有提醒（物業 Tab）。

## SOP-5 · 小測與成績（老師）

**目的**：考後快速登分；期末評語與家長溝通。

| 步驟 | 操作 | 路徑 |
|------|------|------|
| 1 | 建立小測 | 成績 → **📝 小測／考試** |
| 1b | （選）**出題 AI Prompt** | 小測頁 → **W8 出題 AI Prompt** → 複製 → 外部 AI → 人審 |
| 2 | 考後 **載入名單 → 批量登分** | 同上（目標 ≤5 分鐘／班） |
| 3 | 期末 **評語 AI Prompt** | **✨ AI Prompt W8** → 期末成績評語 → 選學生 |
| 4 | 人審評語後 | 面談或 W7 家長通知草稿 |

**完成標準**：成績寫入 `grade.grades`；評語與通知皆經人工發送。

## SOP-6 · 畢業與證書（教務）

**目的**：結業判定、教會培訓履歷、紙本證書。

| 步驟 | 操作 | 路徑 |
|------|------|------|
| 1 | 課程結束，核對及格 | `course_completion.html` 或 成績 → **🎓 結業證書** |
| 2 | 確認寫入中央會員庫 | `training_credits`（結業頁） |
| 3 | **核發＋列印證書** | 結業證書 Tab → 列印 |

**完成標準**：及格者有成績紀錄；證書可列印；教會端可見培訓履歷。

## SOP-7 · 通告（行政）

**目的**：校內公告定稿，經人工發到實際渠道。

| 步驟 | 操作 | 路徑 |
|------|------|------|
| 1 | 撰寫公告 | 溝通 → **公告欄** |
| 2 | （選）多語翻譯 Prompt | **✨ AI Prompt W8** → 通告多語 → 複製 → 人校 |
| 3 | **複製全文**貼到 LINE／WhatsApp／週刊 | 公告頁複製功能 |

**完成標準**：系統內有公告紀錄；對外發送由同工人工完成。

## SOP-8 · 每週備份與交接（管理員）

**目的**：防止單機資料遺失；換機可還原。

| 步驟 | 操作 | 路徑 |
|------|------|------|
| 1 | 每週固定日 **匯出全庫 JSON** | 系統 → **💾 資料備份** |
| 2 | 存兩份 | 本機＋隨身碟或私人雲端資料夾（**勿**放公開 repo） |
| 3 | 換機／交接 | 新機 → **匯入 JSON** |
| 4 | 紀律 | **嚴禁**兩台同時輸入後互相覆蓋 |

**完成標準**：最新備份日期可追；還原測試至少每季做一次。

## SOP-9 · 與教會事工月度對齊（教務＋主日學）

**目的**：名冊一致、缺席有牧養跟進、教師技能回流。

| 步驟 | 操作 | 路徑 |
|------|------|------|
| 1 | **名冊對齊報告** | **🔗 教會連結 W6** → 三欄（已對齊／僅主日學／僅學校） |
| 2 | 處理「僅在一邊」 | 補綁 `memberId` 或確認校外生 |
| 3 | **缺席掃描** → CRM 預填佇列 | 教會連結 → 設定門檻（預設 3）→ 掃描 → 加入佇列 |
| 4 | 探訪同工 **開啟探訪表單** 人工確認 | 佇列 → 開啟 → `visitation_followup/form.html` |
| 5 | 家長關懷（選） | W7 缺席關懷草稿 → 複製發送 |
| 6 | **教師技能回流** | 教會連結 → 更新人才庫技能（須 `volunteerId`） |

**完成標準**：未連結 memberId 數下降；缺席預填已被認領；智慧事奉人才庫有授課技能。

## 附錄 A · W8 AI Prompt 使用步驟（共通）

1. 開 **✨ AI Prompt W8**（側欄或儀表板）。
2. 選任務：招生／評語／出題／多語。
3. 填表 → **生成 Prompt** → **複製**。
4. 貼到 Kimi／ChatGPT／Claude／Gemini。
5. **人工審核**後才用於簡章、試卷、評語或通告。
6. **禁止**：把含學生姓名的 raw 資料丟進 NotebookLM 或公開 API。

## 附錄 B · 常見問題

| 問題 | 處理 |
|------|------|
| 橫幅顯示示範資料 | SOP-1 清種子或重新匯入真實備份 |
| 校長看不到教務輸入的資料 | 單機限制 → SOP-8 匯出／匯入交接 |
| memberId 連結後仍顯示未連結 | 確認非 `sm-stu-*` 自造 ID，須真中央會友 ID |
| 缺席掃描無結果 | 確認點名資料、門檻、學生是否已綁 memberId（或開啟家長 fallback） |
| AI 產出經文錯誤 | 正常 → 必須人查證；Prompt 已含護欄 |
