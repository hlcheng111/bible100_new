🧰 離線工具 / 多校區與語言設定

供各語言地區管理員使用：資料匯出／匯入、多校區與預設語言設定、本站內文 HTML 編輯器（可載入與儲存）。

📖 使用指南

  • 儀表板「關於本校」區：請在下方「本站內 HTML 編輯器」的內容代碼填 dashboard_intro，載入 → 編輯 → 儲存後，回儀表板重新整理即可看到。
  • 其他自訂區：內容代碼可自訂（建議含語言碼，如 school_intro_zh-Hant），同一代碼可隨時載入／儲存／預覽。
  • 匯出／匯入：匯出會下載 JSON 檔；匯入時選檔並可勾選「覆寫現有資料」。
  • 預設校區與語言：選好後按「儲存」即寫入本機，供各模組讀取。

📦 離線資料匯出 / 匯入

從這裡把目前裝置上的 學校資料 + CoreDirectory 匯出成一個 JSON 檔， 拷貝到另一台電腦，再在那邊匯入。完全不需要伺服器。

🏫 多校區 / 🌐 預設語言

設定本裝置目前使用的 預設校區 (organization) 與 預設語言。 各模組日後可以依此顯示對應語言內容。

📝 本站內 HTML 編輯器

供各語言地區管理人員，針對本校區／本語言的介紹頁等內容，直接在瀏覽器內編輯 HTML。 內容會儲存在 localStorage，可隨時載入與回存。

（預覽區：點「預覽」後會顯示上方 HTML 的實際效果）
