## 0. 怎麼用（3 分鐘）

1. 執事會逐列看「建議分類」；可改成 A／B／C，但**不要刪列**（刪＝失蹤債務）。  
2. 投票欄打勾後，本表成為轉型 SSOT；工程只改標為「本週要動」的列。  
3. **儀表板％**只反映 CRM 資料就緒（會友／探訪／志工等契約欄），**不是**「全站功能完工」。DEMO 頁不上綠燈。

### 角標＝平台語言（與本表對齊）

| 角標 | 教會語言 | 轉型處置 |
|------|----------|----------|
| **LIVE** | 可日常用 | 優先對齊 **類 A**（或已決定平移的主路徑） |
| **PARTIAL** | 半成品／可用但不完整 | 多為 **類 B**（雙軌或局部改） |
| **DEMO** | 示範／理念／示意 | **禁止當 LIVE 吹**；雙軌或暫緩，勿接新急事 |

## 2. CRM 資料就緒度（儀表板契約 · 供對照）

`getCrmMaturitySummary()` 檢查項（本機有種子時％會升高）：

| 檢查 id | 含義 | 與上表 |
|---------|------|--------|
| member_master | 會友主檔有資料 | 0-1 / F-2 |
| spiritual_stage | 屬靈階段欄位 | 會友深度 |
| pastoral_events | 牧養事件流 | B／探訪 |
| visitation | 探訪資料可讀 | 0-2 / B-1 |
| volunteer_positions | 志工崗位 | 0-3 / E-1 |
| ministry_catalog | 事工目錄 | 媒合／志工 |
| assignments | 事奉配對紀錄 | DEMO 媒合勿當唯一 |
| timeline_360 | 360 API | 技術就緒 |
