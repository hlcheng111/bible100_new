# B 牧养 · W0 内容规格（教会话 · SSOT）

> 不是「12 页、8 波、六径」的工程表，而是牧者、小组长、会众都听得懂的话。  
> 更新：2026-06

## 牧养要问的六件事

| 教会问题 | 白话 | 系统帮什么（AI 只预填，人决定） |
|----------|------|--------------------------------|
| 人从何来？ | 他第一次怎么认识耶稣、怎么来到教会？ | 整理新朋友名单、招待转交、外展跟进草稿 |
| 人在做什么？ | 他最近有来崇拜、小组、课程吗？ | 汇总出席与参与，提醒「很久没见」 |
| 人属什么？ | 他在哪个小组、团契、服事岗位？ | 小组名册、团契标签，少重复填表 |
| 人如何长大？ | 门训走到哪一步？ | 链主日学／门训，记微小进步 |
| 人如何服事？ | 在哪里同工？会不会太累？ | 链志工、敬拜，提示负荷 |
| 谁帮他？他能帮谁？ | 谁负责关怀？他可带谁？ | 探访接案、资深信徒配对草稿 |

## 三面镜子（认己与方向）

同工与牧者常问的三件事，用教会熟悉的工具接上（链到规划层量表，不在 B 重做一套）：

| 镜子 | 教会话 | 工具入口 |
|------|--------|----------|
| **我是谁** | 恩赐、性格、呼召倾向 | 恩赐／DISC 等调查（`church_planning` 评估页） |
| **我在哪里** | 自己看见与旁人看见的差（盲点） | 约哈里窗 Johari |
| **我去哪里** | 谁负责、谁配合、谁该被告知 | 事奉媒合／岗位搭配（RACI 白话：负责·配合·知情） |

数据只作**配搭与装备参考**，不贴标签、不自动开除小组。

## 六条牧养路（导览用，不是行政抽屉）

| 路 | 适合谁 | 入口 |
|----|--------|------|
| 🕊️ **被牧养之路** | 一般弟兄姊妹、初信 | 会众守望页（待 B7） |
| 🏠 **小组之家** | 组员 | 小组名册（B3） |
| 🌾 **组长禾场** | 小组长 | 一周快评、组员清单（B3） |
| 🤝 **关怀之路** | 探访、招待同工 | `visitation_index.html` |
| 📣 **迎新人之路** | 布道、外展、媒合 | 探访「新朋友」+ 漏斗（B5） |
| ⛪ **牧者守望** | 牧者、长执 | 牧养总桌（B2） |

## 小组 vs 团契（组织需要，不是神学打架）

| | **小组** | **团契** |
|---|----------|----------|
| 重心 | 每周一起读经祷告、彼此守望 | 同阶段、同地区、同职业的朋友相聚 |
| 例子 | 查经小组、夫妇小组 | 青年团契、职场团契、分区联谊 |
| 系统 | 名册、出席、组长快评 | 标签（年龄／地区／职业）、活动 |
| AI 帮什么 | 预填周报草稿、提醒久未出现的人 | 预填活动跟进、推荐合适团契（人确认） |

**原则：** 减文书、减重复登记，让牧者多时间接触人；**不自动派探访、不自动调组**。

| B5 | **新人从哪来** | 迎新人漏斗、外展接探访 |

| B7 | **彼此守望** | 会众只读代祷／预备页 |
| B8 | **看见破口** | 牧养示意雷达、长执决议链规划层 |

## 页面分工（约十来处，不必记数字）

- **导览一页**：`_landing/fellowship.html`（牧羊小径）

- **关怀核心**：`visitation_index.html`（已有，持续加厚）
- **小组／团契**：`modules/fellowship/small-groups.html`、`fellowship-circles.html`（B3/B4）

## 数据与 AI（与 A 敬拜同规）

- **主键**：`memberId` 对齐会友主档
- **关怀事件**：`pastoral_events_v1`、`visitationData`
- **敬拜缺席草稿**：`worship_visitation_drafts_v1` → 探访桌接案
- **AI**：只预填表单、周报、配对建议；邀请与派工由人确认
