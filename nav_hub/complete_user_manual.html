1. 平台介绍

1.1 Bible100是什么？

Bible100是一个完全离线运行的多功能圣经学习和教会管理平台。

1.2 核心特点

  • ✅ 零配置：打开即用，无需安装或设置
  • ✅ 完全离线：除AI工具外，所有功能都可离线使用
  • ✅ 多语言：支持CN、EN、VI、ID、CH、AD共6种语言
  • ✅ 跨平台：PC、平板、手机全支持
  • ✅ 模块化：8大核心模块，200+功能页面
  • ✅ 易维护：新手可独立使用、维护和扩展

1.3 技术架构

  • 📄 前端：纯HTML + CSS + JavaScript，无需服务器
  • 💾 数据：LocalStorage（浏览器本地存储）
  • 🗄️ 数据库：SQLite + JSON双重模式
  • 🎨 样式：Tailwind CSS（本地化CDN）
  • 📊 图表：Chart.js（本地化CDN）

3. 数据管理

3.1 数据存储机制

Bible100使用浏览器LocalStorage存储数据。特点：

  • ✅ 无需数据库服务器
  • ✅ 数据自动保存
  • ✅ 访问速度快
  • ⚠️ 清除浏览器数据会丢失
  • ⚠️ 不同浏览器数据隔离

3.2 如何备份数据？

📥 方法1：使用数据备份中心（推荐）
  1. 打开 nav_hub/data_backup_center.html
  2. 点击"一键备份所有数据"
  3. 保存下载的JSON文件
💡 方法2：在各个页面单独导出

大部分管理页面都有"导出"按钮，可以导出该页面的数据。

3.3 如何恢复数据？

  1. 打开 nav_hub/data_backup_center.html
  2. 选择之前备份的JSON文件
  3. 点击"恢复数据"
  4. 确认后数据将被恢复

4. 核心功能使用

4.1 如何阅读圣经？

  1. 打开 bible_study/index.html
  2. 选择阅读模式（推荐：综合解读）
  3. 选择书卷（如：创世记）
  4. 选择章节（如：第1章）
  5. 开始阅读，可查看注释、串珠

4.2 如何管理诗歌？

步骤1：添加诗歌

  1. 打开 hymn_management/hymn_editor.html
  2. 填写诗歌标题、歌词、作者等
  3. 右侧可以实时预览
  4. 点击"保存诗歌"

步骤2：制作PPT

  1. 打开 hymn_management/ppt_generator.html
  2. 选择诗歌
  3. 调整样式（背景颜色、字体大小、每页行数）
  4. 预览投影片效果
  5. 点击"打印投影片"，选择"另存为PDF"

步骤3：管理版权

  1. 打开 hymn_management/copyright_management.html
  2. 查看所有诗歌的版权状态
  3. 点击"合规性检查"查找缺少版权信息的诗歌
  4. 返回诗歌编辑器补充版权信息

4.3 如何管理教会事工？

会友志工管理：

  1. 打开 church_ministry/member_volunteer_unified.html
  2. 切换"会友"或"志工"标签
  3. 点击"新增"添加记录
  4. 使用搜索和筛选功能查找
  5. 点击"导出CSV"备份数据

发展计划管理：

  1. 打开 church_ministry/modules/development/development-plan.html
  2. 点击"新增计划"
  3. 填写计划信息（名称、类别、负责人、日期等）
  4. 在时间线中追踪进度

6. 常见问题

Q1：数据会丢失吗？

A：数据保存在浏览器中，除非清除浏览器数据，否则不会丢失。但建议定期备份！

Q2：可以多人协作吗？

A：目前不支持实时协作。但可以通过导入导出JSON文件实现数据共享。

Q3：如何更新平台版本？

A：

  1. 在 nav_hub/data_backup_center.html 备份所有数据
  2. 下载新版本，覆盖旧文件
  3. 打开新版本，恢复数据

Q4：为什么综合解读是命脉功能？

A：综合解读模块（comprehensive_exegesis_reader.html）整合了注释书.db，提供最完整的经文解释，是Bible100的核心价值所在。

Q5：可以在手机上使用吗？

A：可以！所有页面都是响应式设计，支持手机和平板访问。

7. 维护与扩展

7.1 如何添加新的注释书？

  1. 准备SQLite格式的注释书数据库（.db文件）
  2. 放到 data/commentaries/ 文件夹
  3. 修改综合解读阅读器的数据库配置

7.2 如何添加新功能页面？

  1. 参考现有页面的HTML结构
  2. 使用统一的CSS样式（Tailwind CSS）
  3. 使用 simple_database_system.js 进行数据操作
  4. 在相应模块的sidebar.html中添加链接

7.3 如何修改样式？

  • 全局样式：css/unified_module_styles.css
  • Tailwind CSS：church_ministry/assets/css/tailwind.min.css
  • 单页样式：在HTML文件的<style>标签中修改

8. 如何編修本站網頁

8.1 HTML 所見即所得編輯器

本站提供 TinyMCE 所見即所得（WYSIWYG）編輯器，可編修網頁內容、插入圖片、連結、YouTube 影片等。

  1. 從頂欄「工具 ▾」→「HTML 編輯器」，或開啟 tools/html_editor.html
  2. 輸入或貼上內容，使用工具列插入圖片、連結、媒體
  3. 點「預覽」檢視效果，「下載 HTML」取得檔案
  4. 將下載的 HTML 內容貼回實際頁面（需手動或由總編輯協助）
